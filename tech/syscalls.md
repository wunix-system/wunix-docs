# Спецификация системных вызовов Wunix (Syscall ABI)

Ядро операционной системы Wunix реализует модульную архитектуру системных вызовов на базе стандартного интерфейса Linux/POSIX:
1. **Linux / POSIX 64-bit ABI**: Фундаментальный интерфейс системных вызовов ядра Wunix. Обеспечивает прямую совместимость с номерами сисколлов x86_64 Linux для запуска стандартных бинарников ELF64 и программ пространства пользователя Ring 3.
2. **Модульная диспетчеризация**: Маршрутизатор системных вызовов изолирует доменные обработчики (`fs`, `mem`, `proc`, `net`, `ipc`) и подготовлен для подключения дополнительных сервисов (включая будущую подсистему `win-init`).

---

## 1. Соглашение о системных вызовах (Calling Convention x86_64)

Системные вызовы инициируются инструкцией процессора `syscall`.

### Передача регистров:
* **`RAX`**: Номер системного вызова (Syscall Number).
* **`RDI`**: 1-й аргумент (`arg1`).
* **`RSI`**: 2-й аргумент (`arg2`).
* **`RDX`**: 3-й аргумент (`arg3`).
* **`R10`**: 4-й аргумент (`arg4`) *(внимание: в системном вызове используется `R10`, а не `RCX`, так как процессор затирает `RCX` адресом возврата `RIP`!)*.
* **`R8`**: 5-й аргумент (`arg5`).
* **`R9`**: 6-й аргумент (`arg6`).

### Возврат значения:
* **Успех**: Регистр `RAX` содержит неотрицательное значение (`0` или положительный результат: количество прочитанных байт, файловый дескриптор, адрес памяти).
* **Ошибка**: Регистр `RAX` содержит отрицательное значение `-Errno` (например, `-2` для `ENOENT`, `-9` для `EBADF`, `-14` для `EFAULT`).
