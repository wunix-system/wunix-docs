# Подсистема оборудования и драйверов Wunix

Драйверная подсистема ядра Wunix построена на полиморфных трейтах Rust и модульном диспетчере устройств `DeviceManager`.

---

## 1. Менеджер устройств (`drivers/manager.rs`)

`DeviceManager` выполняет централизованную регистрацию, шинный опрос (Bus Enumeration) и сопоставление драйверов с обнаруженным оборудованием:

* **Символьные устройства (`CharDevice`)**: посимвольный или потоковый ввод-вывод (терминалы `tty1`–`tty4`, последовательный порт `ttyS0` / COM1, псевдогенератор `urandom`, устройства `null` и `zero`).
* **Блочные устройства (`BlockDevice`)**: блочный ввод-вывод секторами по 512 байт с поддержкой прямого позиционирования (`read_blocks`, `write_blocks`). Сюда относятся контроллеры дисков IDE/ATA (`/dev/hda`), VirtIO-Block (`/dev/vda`) и разделы накопителей (`/dev/hda1`, `/dev/hda2`).

---

## 2. Подсистема шины PCI (`drivers/pci/`)

Ядро реализует полное сканирование шины **PCI (Peripheral Component Interconnect)** по спецификации PCI 3.0:

* **Конфигурационное пространство (Configuration Space)**:
  Доступ к портам ввода-вывода x86:
  * Порт адреса: `CONFIG_ADDRESS` (`0x0CF8`)
  * Порт данных: `CONFIG_DATA` (`0x0CFC`)
* **Формат адресации шины**:
  Битовое поле: `Enable (бит 31) | Bus (биты 23:16) | Device (биты 15:11) | Function (биты 10:8) | Offset (биты 7:2)`.
* **Алгоритм обнаружения**:
  Ядро перебирает шины 0–255, устройства 0–31 и функции 0–7. Если поле `Vendor ID != 0xFFFF`, устройство обнаружено. Считываются поля: `Device ID`, `Class Code`, `Subclass`, `Header Type`, `Interrupt Line` и базовые адресные регистры памяти **BAR0–BAR5** (Base Address Registers).

---

## 3. Архитектура драйверов VirtIO (`drivers/virtio/`)

Для работы в виртуализированных средах (QEMU, KVM, Proxmox) ядро содержит драйверы устройств стандарта **VirtIO Over PCI**:

### Кольцевой буфер Virtqueue
Обмен данными между ядром и гипервизором осуществляется через структуру из трех компонентов:
1. **Descriptor Table**: массив дескрипторов буферов памяти (физический адрес буфера, длина, флаги `NEXT`, `WRITE`).
2. **Available Ring**: кольцо, куда ядро помещает готовые для обработки гипервизором дескрипторы.
3. **Used Ring**: кольцо, куда гипервизор возвращает обработанные дескрипторы после завершения операций ввода-вывода.

### Реализованные устройства VirtIO:
* **`virtio-blk` (Device ID `0x1001` / `0x1042`)**: блочный драйвер жесткого диска (/dev/vdX). Выполняет асинхронное чтение и запись секторов на физический накопитель хоста.
* **`virtio-net` (Device ID `0x1000` / `0x1041`)**: сетевой адаптер (ethX). Содержит очереди приема (Rx) и передачи (Tx).
* **`virtio-gpu` (Device ID `0x1050`)**: видеоадаптер с 2D режимами и аппаратным сканированием буферов.
* **`virtio-input` (Device ID `0x1052`)**: абсолютный указатель мыши и события планшета.
* **`virtio-scsi` (Device ID `0x1004` / `0x1048`)**: высокопроизводительный дисковый контроллер SCSI (/dev/sdX) для QEMU, KVM и Proxmox VE.
* **`virtio-rng` (Device ID `0x1005` / `0x1044`)**: аппаратный источник энтропии для криптографического пула случайных чисел.
* **`virtio-console` (Device ID `0x1003` / `0x1043`)**: виртуальная системная консоль (/dev/hvc0).
* **`virtio-balloon` (Device ID `0x1002` / `0x1045`)**: служба динамического перераспределения оперативной памяти с хостом (Memory Ballooning).

## 4. Драйверы систем виртуализации (`drivers/virt/`)

Ядро Wunix автоматически определяет окружение гипервизора при старте через процессорные инструкции CPUID (лиф 1 бит 31 и сигнатуры гипервизора в листьях `0x4000_0000`..`0x4000_0010`):

### 1. Oracle VM VirtualBox (`drivers/virt/vbox/`)
* **VMMDev (PCI `0x80EE:0xCAFE`)**: системная шина интеграции гостя.
* **VBoxSVGA (PCI `0x80EE:0xBEEF`)**: видеодрайвер с поддержкой VBE DISPI расширений.
* **Мышь без захвата**: опрос абсолютных координат курсора хоста через VMMDev.
* **VBoxSF**: клиент монтирования общих папок хоста в VFS ядра (трейт `FileSystem` и `Inode`).
* **Timesync**: синхронизация точного времени UTC с часами хост-системы.

### 2. VMware Workstation / ESXi (`drivers/virt/vmware/`)
* **Backdoor I/O**: канал связи через порты `0x5658`/`0x5659` и магическое число `0x564D5868` ("VMXh").
* **VMMOUSE**: интеграция абсолютного позиционирования курсора.
* **VMware SVGA II (PCI `0x15AD:0x0405`)**: 32-битный графический контроллер.
* **vmxnet3 (PCI `0x15AD:0x07B0`)**: многоочередной сетевой адаптер 10GbE.
* **PVSCSI (PCI `0x15AD:0x07C0`)**: паравиртуальный SCSI дисковый контроллер.

### 3. Microsoft Hyper-V / Azure VM (`drivers/virt/hyperv/`)
* **Шина VMBus**: транспорт сообщений через кольцевые буферы GPADL.
* **Synthetic Video (PCI `0x1414:0x5353`)**: синтетический видеоконтроллер Hyper-V.
* **NetVSC**: сетевой драйвер по протоколу RNDIS поверх VMBus.
* **StorVSC**: блочный драйвер по протоколу VStor SCSI поверх VMBus.
* **Integration Services**: службы Heartbeat, Guest Shutdown и KVP exchange.

### 4. Xen Hypervisor (`drivers/virt/xen/`)
* **Xen Hypercalls**: страница гипервызовов ядра для прямого взаимодействия с гипервизором Dom0.
* **Grant Tables (v1)**: механизм безопасного совместного использования страниц оперативной памяти.
* **xen-blkfront**: паравиртуальный блочный накопитель (/dev/xvdX).
* **xen-netfront**: паравиртуальный сетевой адаптер.

### 5. Виртуальные узлы `/proc` и `/sys`
* `/proc/hypervisor`: человекочитаемая сводка о текущем гипервизоре, версии и активных драйверах.
* `/sys/hypervisor/type`: системное имя гипервизора (`kvm`, `qemu`, `virtualbox`, `vmware`, `hyperv`, `xen`, `none`).

## 5. Консольный вывод и фреймбуфер (`drivers/display.rs`, `drivers/font.rs`)

Графический вывод организован поверх линейного фреймбуфера Limine:

* **Видеорежим**: 32-битный цвет (RGB/BGR, 4 байта на пиксель), разрешение по умолчанию 1024x768 пикселей.
* **Растровый шрифт 8x16 (`font.rs`)**:
  * Встроенная битовая матрица символов глифов размером 8 на 16 пикселей.
  * Полная таблица символов: стандартный латинский ASCII + кириллица (русский алфавит UTF-8: диапазоны `0x0410`–`0x044F`, буквы `Ё` и `ё`).
* **Парсер ANSI Escape Sequences**:
  * Консоль поддерживает стандарты VT100 / ANSI для раскраски текста (30–37 для цвета текста, 40–47 для фона, атрибуты жирного шрифта и инверсии).

---

## 5. Ввод с клавиатуры PS/2 (`drivers/keyboard.rs`)

* Контроллер клавиатуры 8042 подключен к прерыванию `IRQ 1` (вектор IDT 33).
* Драйвер считывает однобайтовые и двухбайтовые скан-коды (Scan Code Set 1 / Set 2) из порта данных `0x60`.
* Потокобезопасный кольцевой буфер событий клавиатуры на спинлоке.
* Поддержка одновременных модификаторов: `Shift`, `Ctrl`, `Alt`, переключение раскладок **EN / RU** (по комбинации `Alt + Shift`), генерация прерывания `SIGINT` при нажатии `Ctrl + C`.

---

## 6. Часы реального времени CMOS RTC (`drivers/rtc.rs`)

* Микросхема **Motorola MC146818** подключена к портам:
  * Порт индекса: `0x70`
  * Порт данных: `0x71`
* Чтение регистров секунд (`0x00`), минут (`0x02`), часов (`0x04`), дня (`0x07`), месяца (`0x08`) и года (`0x09`).
* Проверка бита обновления `UIP` (Update In Progress) в регистре состояния `Status Register A` во избежание считывания несогласованного времени в момент тика часов.
* Автоматическое преобразование двоично-десятичного формата BCD (Binary Coded Decimal) в стандартный бинарный integer.
