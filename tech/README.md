# Техническая документация ядра Wunix

В этом разделе собрана полная спецификация внутренней архитектуры, низкоуровневых механизмов и системных интерфейсов операционной системы **Wunix**.

---

## 1. Сводные технические характеристики

| Параметр | Значение / Описание |
|---|---|
| **Архитектура CPU** | x86_64 (Intel 64 / AMD64), 64-bit Long Mode |
| **Протокол загрузки** | Limine Boot Protocol v2 (Higher-Half, SMP-ready) |
| **Базовый адрес ядра** | `0xFFFF_8000_0000_0000` (Higher-Half Direct Map) |
| **Базовый адрес кучи** | `0xFFFF_9000_0000_0000` (динамический рост, начальный размер 1–8 МиБ) |
| **Язык разработки** | Rust (nightly, `#![no_std]`, `#![no_main]`) |
| **Интерфейс Ring 0/3** | Инструкция `syscall` / `sysretq` (MSR LSTAR `0xC0000082`) |
| **Модель многозадачности**| Вытесняющая (Preemptive) + кооперативная (Round-Robin, квант 50 мс) |
| **Файловая система VFS**| Гибридная: корень UNIX `/` + проекция дисков Windows `C:\` |
| **Сетевой стек** | Нативный Rust L2/L3/L4 стек поверх VirtIO-Net |
| **Безопасность** | Изоляция страниц Ring 3, валидация буферов, модель UID/GID, POSIX rights |

## 2. Разделы технической документации

1. **[Глубокая архитектура системы](architecture.md)**  
   Инициализация CPU, карты памяти, HHDM, структуры GDT, TSS, IDT и вход через MSR LSTAR.

2. **[Спецификация системных вызовов](syscalls.md)**  
   Исчерпывающая таблица всех системных вызовов Wunix (номера, регистры, параметры, логика и коды ошибок).

3. **[Виртуальная файловая система (VFS)](vfs-and-storage.md)**  
   Трейты `Inode` и `FileSystem`, RAMFS/Initramfs, драйвер FAT32 (LFN), трансляция `C:\` и псевдо-ФС `/proc`.

4. **[Управление процессами и планировщик](process-and-scheduler.md)**  
   Структура TCB, переключение контекста процессора, алгоритм Round-Robin и ELF64 загрузчик.

5. **[Менеджер памяти](memory-management.md)**  
   Физический Frame Allocator (4KiB фреймы), 4-уровневые таблицы страниц PML4, менеджер кучи и изоляция Ring 3.

6. **[Сетевой стек](network-stack.md)**  
   Драйвер VirtIO-Net, кольца Virtqueue, обработка протоколов Ethernet, ARP, IPv4, ICMP, UDP, TCP и сокеты.

7. **[Подсистема драйверов и оборудования](drivers-subsystem.md)**  
   Шина PCI, контроллеры VirtIO, консоль фреймбуфера Limine (кириллица UTF-8, ANSI), контроллер клавиатуры PS/2 и RTC.

8. **[Подсистема локализации (i18n)](i18n-subsystem.md)**  
   Ключ-ориентированный каталог сообщений ядра `MsgKey`, рантайм `tr()` и нулевые накладные расходы.
