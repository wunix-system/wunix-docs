# Подсистема интернационализации ядра (i18n)

Операционная система Wunix изначально проектируется как мультиязычная система. Подсистема `i18n` ([`kernel/src/i18n/`](file:///home/valdis/my-os/wunix/kernel/src/i18n/)) является фундаментальной частью ядра.

---

## 1. Архитектурный принцип: Ключ-ориентированные сообщения

Вместо хардкода строковых литералов в коде функций ядро оперирует строго типизированным перечислением ключей сообщений **`MsgKey`**:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum MsgKey {
    KernelStarting,
    MemoryInitialized,
    SchedulerStarted,
    VfsMounted,
    NetworkReady,
    UserLoggedIn,
    PermissionDenied,
    FileNotFound,
    // ...
}
```

---

## 2. Каталог переводов и рантайм `tr()`

Ядро поддерживает выбор системного языка (`Language::Ru`, `Language::En`).

### Функция перевода `tr()`:
```rust
pub fn tr(key: MsgKey) -> &'static str {
    let lang = CURRENT_LANGUAGE.load(Ordering::Relaxed);
    match (lang, key) {
        (Language::Ru, MsgKey::KernelStarting) => "Ядро Wunix запускается...",
        (Language::En, MsgKey::KernelStarting) => "Wunix kernel is starting...",
        // ...
    }
}
```

### Преимущества подхода:
1. **Нулевые накладные расходы (Zero-Cost Allocation)**: Строковые литералы хранятся в секции `.rodata` ядра. При переводе не выделяется память в куче, не происходит форматирования или копирования байт.
2. **Гарантия полноты переводов на этапе компиляции**: Компилятор Rust гарантирует, что если в `enum MsgKey` добавлен новый ключ, `match` в каталоге переводов обязан содержать ветки для каждого поддерживаемого языка. Пропустить перевод невозможно.
3. **Безопасность в обработчиках прерываний**: Функцию `tr()` можно безопасно вызывать внутри обработчиков исключений и прерываний, где аллокации в куче категорически запрещены.
