# Управление дисками, разметкой и накопителями

В операционной системе Wunix поддерживается работа с блочными устройствами IDE/ATA (`/dev/hda`), VirtIO-Block (`/dev/vda`) и сменными носителями через абстракцию `BlockDevice`.

---

## 1. Просмотр накопителей (`lsblk`)

Утилита `lsblk` сканирует блочные устройства ядра и выводит список всех дисков и найденных разделов MBR:

```bash
lsblk
```

Пример вывода:
```text
NAME    MAJ:MIN SIZE   TYPE  MOUNTPOINT
hda       3:0   10.0G  disk  
├─hda1    3:1    512M  part  /boot
└─hda2    3:2    9.5G  part  /mnt
vda     254:0   20.0G  disk  
└─vda1  254:1   20.0G  part  /win/drives/c
```

---

## 2. Разметка диска (`fdisk`)

Для создания и редактирования таблиц разделов MBR используется интерактивная утилита `fdisk`:

```bash
sudo fdisk /dev/hda
```

### Основные команды `fdisk`:
* `p` — вывести текущую таблицу разделов диска.
* `n` — создать новый раздел (Primary 1–4, задание первого и последнего секторов).
* `t` — изменить тип файловой системы раздела (например, `0x0C` для FAT32 LBA, `0x83` для Linux/Wunix).
* `a` — сделать раздел загрузочным (переключить флаг Bootable `0x80`).
* `d` — удалить раздел.
* `w` — записать новую таблицу разделов на диск и выйти.
* `q` — выйти без сохранения изменений.

После записи таблицы ядро Wunix выполняет автоматический рескан блочного устройства и мгновенно регистрирует новые дочерние разделы (`/dev/hda1`, `/dev/hda2`) в менеджере устройств.

---

## 3. Монтирование файловых систем (`mount` и `umount`)

Ядро Wunix поддерживает прямое монтирование файловых систем FAT16/FAT32 с поддержкой длинных имен файлов (LFN — Long File Names).

### Монтирование раздела (`mount`)
Для подключения постоянного раздела к дереву каталогов:
```bash
# Создаем точку монтирования
sudo mkdir -p /mnt/data

# Монтируем постоянный раздел FAT32
sudo mount -t vfat /dev/hda1 /mnt/data
```

### Проекция в пространство Windows (Диск C:\)
Для постоянного монтирования накопителя в качестве диска `C:\`:
```bash
sudo mount -t vfat /dev/vda1 /win/drives/c
```
После этого любые операции с путями `C:\...` будут сохраняться на постоянном физическом накопителе.

### Безопасное отмонтирование (`umount`)
Перед извлечением накопителя или выключением необходимо сбросить кэши ядра и отмонтировать раздел:
```bash
sudo umount /mnt/data
```
Если файловая система занята открытыми файлами процессов, `umount` вернет ошибку `EBUSY`. Завершите работающие с диском процессы и повторите команду.
