# Руководство системного администратора Wunix

В данном разделе описаны принципы администрирования, управления безопасностью, накопителями, сетевой подсистемой и жизненным циклом операционной системы **Wunix**.

---

## 1. Архитектура безопасности и привилегий

Операционная система Wunix построена на строгом разделении привилегий между пространством ядра (Ring 0) и пространством пользователя (Ring 3).

### Модель идентификации (UID / GID)
* **Суперпользователь (`root`, UID = 0, GID = 0)**: обладает абсолютными правами на все системные вызовы ядра. Только `root` может выполнять прямое конфигурирование сетевых интерфейсов, монтирование файловых систем, разметку дисков, изменение владельцев файлов и перезагрузку ОС.
* **Обычные пользователи (UID >= 1000)**: ограничены доступом к собственным домашним директориям `/home/<user>`, временным файлам `/tmp` и общедоступным системным бинарникам `/bin`.

### Административный доступ через `sudo`
Wunix реализует концепцию повышения привилегий через утилиту `sudo`. Пользователи, добавленные администратором в список доверенных через `sudoadd`, могут выполнять привилегированные команды с подтверждением своего пароля.

## 2. Разделы руководства администратора

1. **[Пользователи, группы и права доступа](users-and-groups.md)**  
   Работа с базами `/etc/passwd` и `/etc/shadow`, создание пользователей через `useradd`, удаление через `userdel`, управление sudoers и правами файлов (`chmod`, `chown`).

2. **[Диски, разметка и хранилище](disk-and-storage.md)**  
   Инвентаризация дисков через `lsblk`, создание таблиц разделов MBR через `fdisk`, монтирование файловых систем FAT32 через `mount`/`umount`.

3. **[Сетевое администрирование](network.md)**  
   Конфигурация сетевых адаптеров VirtIO через утилиту `ip`, мониторинг сокетов через `ss`, диагностика задержек через `ping` и настройка DNS.

4. **[Установка системы на диск](installation.md)**  
   Развертывание Wunix на постоянный диск с помощью псевдографического инсталлятора `winstall`, установка загрузчика Limine и генерация `/boot`.

5. **[Службы, время и выключение](system-services.md)**  
   Процесс `init` (PID 1), настройка системных часов через `timedatectl` и `hwclock`, команды выключения `shutdown` и перезагрузки `reboot`.
