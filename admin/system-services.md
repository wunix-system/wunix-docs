# Службы, системное время и управление питанием

В этом разделе описано управление жизненным циклом операционной системы Wunix, процесс инициализации и настройка системных часов.

---

## 1. Процесс инициализации `init` (PID 1)

После того как ядро завершит базовый bring-up оборудования и инициализацию подсистемы VFS, запускается первый пользовательский процесс в Ring 3: **`/bin/init`** (PID 1).

### Обязанности `init`:
1. Монтирование виртуальных псевдофайловых систем:
   * `/dev` — виртуальные символьные устройства (консоли, null, zero).
   * `/proc` — динамическая статистика ядра и процессов.
   * `/sys` — дерево оборудования и шины PCI.
2. Инициализация постоянных дисковых разделов из таблицы `/etc/fstab`.
3. Поднятие сетевого интерфейса по умолчанию (`eth0`) и установка маршрутов.
4. Запуск терминального демона входа `login` на виртуальных консолях `tty1`–`tty4`.
5. Сбор завершившихся процессов-зомби (reaping zombie child processes) через системный вызов `wait4`.

## 2. Системное время и аппаратные часы (`timedatectl` и `hwclock`)

В Wunix время поддерживается на двух уровнях:
1. **Системные часы ядра (System Time)**: непрерывный счетчик тиков таймера PIT/APIC с момента старта эпохи Unix (1 января 1970 года).
2. **Аппаратные часы реального времени (Hardware RTC)**: микросхема CMOS MC146818 на материнской плате с автономным питанием от батарейки.

### `timedatectl` — управление системным временем
Показывает текущее время, статус синхронизации и часовой пояс:
```bash
timedatectl status
```
Установка системного времени:
```bash
sudo timedatectl set-time "2026-11-02 14:30:00"
```

### `hwclock` — синхронизация с CMOS
* Чтение аппаратного времени:
  ```bash
  sudo hwclock
  ```
* Запись текущего системного времени ядра в микросхему RTC:
  ```bash
  sudo hwclock --systohc
  ```
* Установка системного времени из микросхемы RTC:
  ```bash
  sudo hwclock --hctosys
  ```

## 3. Завершение работы и перезагрузка

Выключение и перезагрузка являются привилегированными операциями суперпользователя.

### `shutdown` — безопасная остановка системы
Команда `shutdown` отправляет сигнал завершения всем активным процессам, выполняет принудительный сброс дисковых буферов на постоянные накопители (`sync`), безопасно отмонтирует файловые системы и выключает питание компьютера (через ACPI / APM / QEMU port `0x604`):
```bash
sudo shutdown -h now
```

### `reboot` — быстрая перезагрузка
Перезагружает центральный процессор через контроллер клавиатуры 8042 (pulse reset line) или тройное исключение CPU (triple fault):
```bash
sudo reboot
```
