# Установка системы на постоянный диск (`winstall`)

Операционная система Wunix поставляется с собственным интерактивным TUI-инсталлятором **`winstall`**, позволяющим развернуть систему на виртуальный накопитель (QEMU/KVM, VirtualBox, VMware) или реальный диск ПК.

---

## 1. Запуск инсталлятора

Для перехода к установке:
1. Загрузите систему в режиме `2. Wunix Installer` из стартового меню Limine.
2. Либо запустите установщик вручную из Live-сессии под учетной записью суперпользователя:
   ```bash
   sudo winstall
   ```

---

## 2. Пошаговый процесс развертывания

Инсталлятор `winstall` работает в удобном текстовом псевдографическом режиме (TUI) с навигацией стрелками и клавишей `Enter`.

### Шаг 1: Выбор целевого диска
Программа отображает список доступных блочных устройств (`/dev/hda`, `/dev/vda`):
```text
┌────────────────── Выбор целевого накопителя ──────────────────┐
│ [X] /dev/hda  (QEMU HARDDISK, 10.0 GiB)                       │
│ [ ] /dev/vda  (VirtIO Block Device, 20.0 GiB)                 │
│                                                               │
│                   < Выбрать >     < Отмена >                  │
└───────────────────────────────────────────────────────────────┘
```

### Шаг 2: Стратегия разметки
* **Автоматическая разметка (Рекомендуется)**:
  * Создает системный раздел MBR размером 512 МБ под `/boot` (FAT32, флаг загрузки `0x80`).
  * Создает основной корневой раздел под систему и постоянный диск `C:\`.
* **Ручная разметка**:
  * Запускает утилиту `fdisk` для задания геометрии разделов администратором.

### Шаг 3: Деплой ядра и системных компонентов
После подтверждения разметки инсталлятор автоматически:
1. Создает файловую структуру FAT32 на целевых разделах.
2. Копирует 64-битный исполняемый образ ядра `wunix.elf` в `/boot/wunix.elf`.
3. Копирует корневой архив пользовательского пространства `initramfs.tar` в `/boot/initramfs.tar`.
4. Разворачивает загрузочные бинарники загрузчика **Limine** (`limine-bios.sys`, `limine-bios-cd.bin`).
5. Генерирует конфигурационный файл `/boot/limine.cfg`:
   ```text
   TIMEOUT=3
   :Wunix OS
   PROTOCOL=limine
   KERNEL_PATH=boot:///boot/wunix.elf
   MODULE_PATH=boot:///boot/initramfs.tar
   ```
6. Прошивает загрузочный сектор MBR (Stage 1 / VBR) на диск для обеспечения автономного старта без Live-CD.

---

## 3. Завершение установки и первый запуск

По завершении копирования появится поздравительное сообщение:
```text
Установка Wunix успешно завершена! Извлеките установочный диск и перезагрузите компьютер.
```

Перезагрузите систему командой:
```bash
sudo reboot
```
При следующей загрузке ПК стартует уже непосредственно с вашего жесткого диска.
