# Сетевое администрирование Wunix

Операционная система Wunix оснащена собственным высокопроизводительным сетевым стеком, написанным на чистом Rust. Он работает поверх виртуального сетевого контроллера **VirtIO-Net** (или PCI Ethernet).

---

## 1. Конфигурация сетевых интерфейсов (`ip`)

Утилита `ip` является основным инструментом управления сетевыми адаптерами, IP-адресами и таблицей маршрутизации ядра.

### Просмотр интерфейсов
```bash
ip link show
ip addr show
```
Пример вывода:
```text
1: lo: <LOOPBACK,UP> mtu 65536
    inet 127.0.0.1/8 scope host lo
2: eth0: <BROADCAST,MULTICAST,UP> mtu 1500
    link/ether 52:54:00:12:34:56
    inet 192.168.1.50/24 scope global eth0
```

### Назначение статического IP-адреса
Для настройки сетевого адреса и маски подсети:
```bash
sudo ip addr add 192.168.1.100/24 dev eth0
```

### Включение и отключение интерфейса
```bash
sudo ip link set eth0 up
sudo ip link set eth0 down
```

### Настройка шлюза по умолчанию (Default Gateway)
Для направления интернет-трафика через маршрутизатор:
```bash
sudo ip route add default via 192.168.1.1 dev eth0
```

## 2. Диагностика сети (`ping`)

Утилита `ping` использует протокол **ICMP (Internet Control Message Protocol)** для проверки доступности узлов сети:

```bash
ping 192.168.1.1
```
Ключевые флаги:
* `-c КОЛИЧЕСТВО` — отправить указанное число эхо-запросов (по умолчанию 4):
  ```bash
  ping -c 3 8.8.8.8
  ```

Пример вывода:
```text
PING 192.168.1.1 (192.168.1.1) 56(84) bytes of data.
64 bytes from 192.168.1.1: icmp_seq=1 ttl=64 time=1.23 ms
64 bytes from 192.168.1.1: icmp_seq=2 ttl=64 time=0.98 ms
--- 192.168.1.1 ping statistics ---
2 packets transmitted, 2 received, 0% packet loss, time 1002ms
```

## 3. Мониторинг сокетов (`ss`)

Утилита `ss` (Socket Statistics) выводит подробную информацию об активных сокетах ядра (TCP, UDP, UNIX Domain Sockets):

```bash
ss -tuna
```
Ключевые флаги:
* `-t` — отображать TCP-сокеты.
* `-u` — отображать UDP-сокеты.
* `-l` — показывать только слушающие сокеты (`LISTEN`).
* `-a` — показывать все сокеты (включая установленные соединения `ESTABLISHED`).
* `-n` — выводить числовые номера портов вместо имен служб.

Пример вывода:
```text
Netid  State      Local Address:Port       Peer Address:Port
tcp    LISTEN     0.0.0.0:80               0.0.0.0:*
tcp    ESTAB      192.168.1.50:42100       93.184.216.34:80
udp    UNCONN     0.0.0.0:53               0.0.0.0:*
```

## 4. Настройка разрешения доменных имен (DNS)

Серверы разрешения имен задаются в стандартном файле `/etc/resolv.conf`:

```text
nameserver 1.1.1.1
nameserver 8.8.8.8
```

После указания DNS-серверов утилиты `host` и `curl` автоматически преобразуют текстовые домены в IP-адреса.
