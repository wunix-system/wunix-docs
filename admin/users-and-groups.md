# Управление пользователями, группами и безопасностью

В операционной системе Wunix реализована классическая POSIX-совместимая многопользовательская модель безопасности.

---

## 1. Конфигурационные файлы базы пользователей

Информация об учетных записях и учетных данных хранится в стандартных файлах каталога `/etc`:

* **`/etc/passwd`** — публичные метаданные учетных записей (права доступа: `644`):
  ```text
  root:x:0:0:root:/root:/bin/wsh
  user:x:1000:1000:user:/home/user:/bin/wsh
  ```
  Формат полей: `логин:заглушка_пароля:UID:GID:GECOS(комментарий):домашний_каталог:оболочка`.

* **`/etc/shadow`** — защищенная база хэшей паролей (права доступа: `600`, доступна только `root`):
  ```text
  root:$6$salt$hash...:19000:0:99999:7:::
  user:$6$salt$hash...:19000:0:99999:7:::
  ```

* **`/etc/group`** — перечень системных и пользовательских групп:
  ```text
  root:x:0:
  sudo:x:27:user
  user:x:1000:
  ```

* **`/etc/sudoers`** — список пользователей и групп, имеющих право повышать привилегии до уровня `root`.

## 2. Утилиты управления учетными записями

### `useradd` — создание нового пользователя
Создает новую учетную запись, резервирует уникальный UID, добавляет запись в `/etc/passwd` и `/etc/shadow`, а также создает домашний каталог с правильными правами доступа:
```bash
sudo useradd -m -s /bin/wsh developer
```
Ключевые флаги:
* `-m` — автоматически создать домашний каталог (`/home/developer`).
* `-u UID` — явно задать числовой идентификатор пользователя.
* `-s ШЕЛЛ` — назначить командную оболочку (по умолчанию `/bin/wsh`).

### `passwd` — установка или сброс пароля
Администратор может назначить пароль любому пользователю системы без запроса старого пароля:
```bash
sudo passwd developer
```
При вводе нового пароля символы защищаются звездочками `*`.

### `userdel` — удаление пользователя
Удаляет учетную запись из системы:
```bash
sudo userdel -r developer
```
Ключевые флаги:
* `-r` — удалить домашний каталог пользователя вместе со всеми файлами.

## 3. Делегирование прав: `sudo` и `sudoadd`

### `sudoadd` — добавление администратора
Утилита `sudoadd` добавляет указанного пользователя в группу `sudo` в файле `/etc/group` и регистрирует его в `/etc/sudoers`:
```bash
sudo sudoadd developer
```
После этого пользователь `developer` получает возможность выполнять команды с правами суперпользователя.

### `sudo` — выполнение привилегированной команды
Выполняет одну команду от имени `root`:
```bash
sudo fdisk /dev/hda
```
При первом запуске запрашивается пароль текущего пользователя.

## 4. Разграничение прав на файлы (`chmod` и `chown`)

Ядро Wunix строго проверяет биты прав доступа `rwx` при каждом системном вызове `sys_open`, `sys_read`, `sys_write` и `sys_execve`.

### `chmod` — изменение режима доступа
* **Синтаксис**: `chmod РЕЖИМ ФАЙЛ...`
* Восьмеричный режим:
  ```bash
  chmod 755 /bin/my_tool       # rwxr-xr-x
  chmod 600 /etc/shadow        # rw-------
  chmod 777 /tmp               # rwxrwxrwx
  ```
* Поддержка бита SUID (`4000`):
  ```bash
  chmod 4755 /bin/sudo         # rwsr-xr-x (запуск с правами владельца root)
  ```

### `chown` — смена владельца и группы
* **Синтаксис**: `chown [ВЛАДЕЛЕЦ][:ГРУППА] ФАЙЛ...`
* Примеры:
  ```bash
  sudo chown -R user:user /home/user/data
  sudo chown root:root /etc/shadow
  ```
