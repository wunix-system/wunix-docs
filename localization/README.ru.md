# Подсистема локализации Wunix

Настоящий документ описывает архитектуру и механизмы интернационализации и локализации ядра операционной системы **Wunix**.

---

## 1. Архитектурные принципы

Ядро Wunix функционирует в автономной среде без стандартной библиотеки (`no_std`) и обеспечивает локализацию на этапе ранней загрузки оборудования до монтирования файловых систем.

Основные архитектурные решения подсистемы:

1. **Атомарное хранение состояния (Lock-Free)**:
   Идентификатор активного языка хранится в глобальной переменной `AtomicU8` ([`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs)). Это гарантирует безопасное чтение языка из любого контекста выполнения (включая обработчики аппаратных прерываний) без риска взаимных блокировок.

2. **Типобезопасный каталог системных сообщений (`MsgKey` и `tr`)**:
   Все ключевые системные сообщения ядра типизированы через перечисление `MsgKey`. Компилятор Rust гарантирует полноту сопоставления (`exhaustive match`): если для любого языка отсутствует сопоставление хотя бы одного ключа, процесс компиляции завершается ошибкой.

3. **Парный инлайн-перевод (`t`)**:
   Вспомогательная функция `t(ru, en)` предназначена для быстрой подстановки коротких парных строк в форматированный вывод.

4. **Двойная раскладка клавиатуры**:
   Драйвер клавиатуры ([`kernel/src/drivers/keyboard.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/keyboard.rs)) поддерживает переключение между раскладками по сочетанию `Alt+Shift` и гарантирует сквозную обработку управляющих комбинаций (`Ctrl+C`) независимо от активного языка.

5. **Растровый знакогенератор 8×16**:
   Графический вывод символов ([`kernel/src/drivers/font.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/font.rs)) основан на моноширинных растровых матрицах 8×16 пикселей. Подсистема поддерживает символы ASCII, кириллицу и расширяется произвольными национальными глифами.

## 2. Параметры командной строки ядра (cmdline)

Ядро определяет язык интерфейса при инициализации на основе параметров, переданных загрузчиком Limine через `ExecutableFileRequest`.

Поддерживаемые параметры:
- `lang=<код>` (например, `lang=ru`, `lang=en`, `lang=de`);
- `locale=<код>` (например, `locale=ru_RU`, `locale=en_US`, `locale=de_DE`);
- Короткие позиционные идентификаторы языка (`ru`, `en`, `de`).

Конфигурация меню выбора языка задается в файле загрузчика `limine.conf`:

```ini
/Wunix OS (Russian)
    protocol: limine
    kernel_path: boot():/boot/wunix-kernel
    cmdline: lang=ru

/Wunix OS (English)
    protocol: limine
    kernel_path: boot():/boot/wunix-kernel
    cmdline: lang=en
```

## 4. Исходный код подсистемы

- [`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs) — перечисление `Language`, каталог `MsgKey`, диспетчер `tr()`, функция `t()`, парсер `init_from_cmdline()`.
- [`kernel/src/drivers/font.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/font.rs) — знакогенератор 8×16, растровые таблицы ASCII и Cyrillic, функция `get_glyph()`.
- [`kernel/src/drivers/keyboard.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/keyboard.rs) — драйвер клавиатуры PS/2, обработка скан-кодов, переключение раскладок по `Alt+Shift`.
