# Дорожная карта и статус разработки Wunix

Данный документ фиксирует этапы развития ядра и базовой системы Wunix, текущий прогресс и детальный список задач.

---

## 1. Сводная таблица этапов разработки

| № | Фаза разработки | Ключевые компоненты | Статус | Результат / Критерий готовности |
|:---:|:---|:---|:---:|:---|
| **1** | **Аппаратный Bring-up и CPU** | GDT, TSS, IST0, IDT, PIC 8259, Serial COM1, Limine, локализация | ✅ **Завершено** | Ядро стабильно грузится в 64-bit Long Mode, обрабатывает прерывания CPU, поддерживает локализацию. |
| **2** | **Менеджер памяти** | Frame Allocator, Paging (HHDM), Heap (1 MiB), `alloc` | ✅ **Завершено** | Динамическая память (`Box`, `Vec`, `String`), куча в Higher-Half (`0xFFFF_9000_...`), UNIX autoconfig лог. |
| **3** | **Ввод и системные таймеры** | Клавиатура PS/2 (Ring Buffer, Alt+Shift), PIT 8254 Timer | ✅ **Завершено** | Потокобезопасная очередь ввода, системный счетчик времени (`uptime`), обработка `Ctrl+C`. |
| **4** | **Многозадачность ядра** | TCB, стеки потоков, `context_switch`, планировщик | 🔄 **В работе** | Вытесняющая многозадачность по тику таймера, изоляция стеков потоков ядра. |
| **5** | **VFS и файловые системы** | Трейты VFS, Ramdisk / Initramfs (TAR), DeviceManager | ⏳ *Запланировано* | Монтирование корневой ФС (`/`), чтение первых файлов и модулей ядра с рамдиска. |
| **6** | **Userland (Ring 3)** | Изоляция памяти процесса, `syscall` / `sysret`, ELF-парсер | ⏳ *Запланировано* | Переход CPU в Ring 3 с разделением привилегий, обработка быстрых системных вызовов. |
| **7** | **Первый процесс и WSH** | Процесс `/bin/init`, Wunix Shell, базовые утилиты | ⏳ *Запланировано* | Интерактивная консоль пользователя в Ring 3. |

## 2. Архитектурный конвейер

```
[1. Bring-up железа] (GDT, IDT, PIC, Framebuffer, Serial, Limine) ──► [ВЫПОЛНЕНО]
         │
         ▼
[2. Менеджер памяти] (Higher-Half, Paging, 1MiB Heap, alloc) ───────► [ВЫПОЛНЕНО]
         │
         ▼
[3. Базовый ввод и таймеры] (PS/2 буфер, Alt+Shift, PIT 100 Гц) ─────► [ВЫПОЛНЕНО]
         │
         ▼
[4. Многозадачность] (Потоки ядра, переключение контекста) ──────────► [В РАБОТЕ]
         │
         ▼
[5. Файловая система и VFS] (Загрузка ramdisk / initramfs)
         │
         ▼
[6. Переход в Ring 3] (Изоляция User Space, syscall / sysret)
         │
         ▼
[7. Первый процесс: init / wsh] ────► Пользовательский режим (WSH)
```

## 3. Детальный статус задач

### Фаза 1: Аппаратный Bring-up и загрузка
- [x] Дескрипторы GDT и сегмент состояния задачи TSS.
- [x] Аварийный стек IST0 (20 КБ) для перехвата исключения Double Fault.
- [x] Таблица векторов прерываний IDT (Breakpoint, Double Fault, Page Fault).
- [x] Ремаппинг контроллера прерываний 8259 PIC на векторный диапазон `32..47`.
- [x] Драйвер последовательного порта UART 16550 (COM1, порт `0x3F8`) для вывода отладки в терминал.
- [x] Загрузчик **Limine v0.6.5** (Higher-Half, поддержка UEFI и BIOS).
- [x] Модульная структура ядра по стандарту раздела 5 AGENTS.md.
- [x] Подсистема локализации ядра с поддержкой RU и EN при загрузке.

### Фаза 2: Подсистема памяти
- [x] Подключение смещения Limine HHDM (Higher-Half Direct Map).
- [x] Инициализация транслятора таблиц страниц 4-го уровня через `OffsetPageTable`.
- [x] Аллокатор физических страниц `LimineFrameAllocator` (выделение 4 КиБ фреймов из `MEMMAP_USABLE`).
- [x] Подключение легковесного аллокатора кучи `linked_list_allocator` и включение `extern crate alloc`.
- [x] Размещение кучи в Higher-Half (`0xFFFF_9000_0000_0000`, 1 МиБ).
- [x] Структура `MemoryStats` с подсчетом реального и доступного объема памяти (`real mem`, `avail mem`).
- [x] Строгий UNIX/BSD стиль автоконфигурации устройств при старте ядра.

### Фаза 3: Драйверы базового ввода и системные таймеры
- [x] Драйвер клавиатуры PS/2 с кольцевым буфером событий (`RingBuffer<char, 128>`).
- [x] Поддержка модификаторов Shift, Ctrl, Alt, CapsLock.
- [x] Двойная раскладка клавиатуры (EN / RU) с переключением по `Alt+Shift`.
- [x] Обработка прерывания `Ctrl+C` с отменой текущей строки ввода.
- [x] Инициализация системного таймера PIT 8254 (100 Гц, делитель 11932).
- [x] Глобальный атомарный счетчик тиков и функция системного времени `uptime_ms`.

### Фаза 4: Многозадачность и планировщик ядра (текущая)
- [ ] Структура блока управления потоком (TCB — Thread Control Block).
- [ ] Выделение индивидуальных стеков для потоков ядра.
- [ ] Ассемблерная процедура сохранения и восстановления регистров CPU (`context_switch`).
- [ ] Кооперативное переключение потоков (`yield_now`).
- [ ] Вытесняющий планировщик задач (Preemptive Round-Robin) по тику таймера PIT.
- [ ] Примитивы синхронизации ядра: спинлоки (`SpinMutex`), спящие блокировки и очереди ожидания.
