# Дорожная карта и статус разработки Wunix

Данный документ фиксирует этапы развития ядра и базовой системы Wunix, текущий прогресс и детальный список задач.

---

## 3. Детальный статус задач

### Фаза 1: Аппаратный Bring-up и загрузка
- [x] Дескрипторы GDT и сегмент состояния задачи TSS.
- [x] Аварийный стек IST0 (20 КБ) для перехвата исключения Double Fault.
- [x] Таблица векторов прерываний IDT (Breakpoint, Double Fault, Page Fault).
- [x] Ремаппинг контроллера прерываний 8259 PIC на векторный диапазон `32..47`.
- [x] Драйвер последовательного порта UART 16550 (COM1, порт `0x3F8`) для вывода отладки в терминал.
- [x] Загрузчик **Limine v0.6.5** (Higher-Half, поддержка UEFI и BIOS).
- [x] Модульная структура ядра по стандарту раздела 5 AGENTS.md.
- [x] Подсистема локализации ядра с поддержкой RU и EN при загрузке.

### Фаза 2: Подсистема памяти
- [x] Подключение смещения Limine HHDM (Higher-Half Direct Map).
- [x] Инициализация транслятора таблиц страниц 4-го уровня через `OffsetPageTable`.
- [x] Аллокатор физических страниц `LimineFrameAllocator` (выделение 4 КиБ фреймов из `MEMMAP_USABLE`).
- [x] Подключение легковесного аллокатора кучи `linked_list_allocator` и включение `extern crate alloc`.
- [x] Размещение кучи в Higher-Half (`0xFFFF_9000_0000_0000`, 1 МиБ).
- [x] Структура `MemoryStats` с подсчетом реального и доступного объема памяти (`real mem`, `avail mem`).
- [x] Строгий UNIX/BSD стиль автоконфигурации устройств при старте ядра.

### Фаза 3: Драйверы базового ввода и системные таймеры
- [x] Драйвер клавиатуры PS/2 с кольцевым буфером событий (`RingBuffer<char, 128>`).
- [x] Поддержка модификаторов Shift, Ctrl, Alt, CapsLock.
- [x] Двойная раскладка клавиатуры (EN / RU) с переключением по `Alt+Shift`.
- [x] Обработка прерывания `Ctrl+C` с отменой текущей строки ввода.
- [x] Инициализация системного таймера PIT 8254 (100 Гц, делитель 11932).
- [x] Глобальный атомарный счетчик тиков и функция системного времени `uptime_ms`.

### Фаза 4: Многозадачность и планировщик ядра
- [x] Структура блока управления потоком (TCB — Thread Control Block).
- [x] Выделение индивидуальных стеков для потоков ядра (32 КиБ).
- [x] Ассемблерная процедура сохранения и восстановления регистров CPU (`context_switch`).
- [x] Кооперативное переключение потоков (`yield_now`).
- [x] Вытесняющий планировщик задач (Preemptive Round-Robin, квант 50 мс) по тику таймера PIT.
- [x] Очистка стеков завершенных потоков (`garbage` в `Scheduler`).

### Фаза 5: Виртуальная файловая система (VFS) и Ramdisk
- [x] Трейты абстракции VFS: `Inode`, `FileSystem`, `Metadata`, `DirEntry`, `VfsError`.
- [x] In-memory файловая система `RamFs` с потокобезопасными узлами (`RamInode`).
- [x] Поддержка путей Windows NT (`C:\...`) и регистронезависимого поиска.
- [x] Модуль распаковки архивов TAR ustar (`unpack_tar`) в иноды VFS.
- [x] Загрузка initramfs архива через протокол Limine.
- [x] Гибридная структура каталогов Unix и NT (`/bin`, `/etc`, `C:\Windows`, `/home/user`).

### Фаза 6: Пространство пользователя (Ring 3) и системные вызовы
- [x] Преобразование проекта в Cargo Workspace (`kernel`, `libs/libwunix`).
- [x] Настройка дескрипторов GDT для Ring 3 (User Code 0x20, User Data 0x18) и стека ядра `rsp0` в TSS (32 КиБ).
- [x] Настройка MSR-регистров x86_64 для поддержки инструкций `syscall` / `sysret` (`IA32_STAR`, `IA32_LSTAR`, `IA32_FMASK`, `EFER.SCE`).
- [x] Ассемблерная точка входа `syscall_entry` с переключением стека, сохранением контекста и System V calling convention.
- [x] Диспетчер системных вызовов (`sys_write`, `sys_read`, `sys_exit`, `sys_yield`) с валидацией пользовательских указателей.
- [x] Изолированные адресные пространства процессов (`UserAddressSpace`: отдельный PML4, пустая младшая половина, общее Higher-Half ядра).
- [x] Настройка флагов страниц User/Supervisor (`PageTableFlags::USER_ACCESSIBLE`) для кода и стека пользователя.
- [x] Обработка исключений `#GP` и `#PF` из пользовательского пространства с изоляцией и аварийным завершением процесса.
- [x] Пользовательская no_std библиотека системных вызовов `libwunix` (`wunix/libs/libwunix`).
- [x] Успешная верификация Ring 3: выполнение `sys_write` / `sys_exit` и перехват привилегированных инструкций `#GP`.

### Фаза 7: Пользовательская среда (Userland) и Wunix Shell
- [x] Загрузчик и парсер исполняемых файлов ELF64 (`kernel/src/task/elf.rs`): загрузка секций `PT_LOAD`, маппинг в PML4 Ring 3, зануление BSS.
- [x] Первый пользовательский процесс инициализации: `/bin/init` (PID 1) со спавном шелла и супервизор-циклом.
- [x] Консольный драйвер терминала (TTY): поддержка цветов ANSI SGR, инвертирующий курсор, буферизованный ввод.
- [x] Системные вызовы Userland: `SYS_EXECVE` (передача argc/argv по System V ABI), `SYS_OPEN`, `SYS_CLOSE`, `SYS_UNLINK`, `SYS_GETCWD`, `SYS_CHDIR`, `SYS_SYSINFO`, `SYS_UNAME`, `SYS_GETDENTS64`.
- [x] Базовая командная оболочка `wsh` (Wunix Shell): интерактивный LineEditor со стрелками, история, prompt (`valdis@wunix:~$ ` / `C:\> `), встроенные команды (`cd`, `help`, `history`, `clear`, `exit`), запуск бинарников.
- [x] Портирование и компиляция базовых UNIX-утилит в `/bin/`: `init`, `wsh`, `echo`, `cat`, `ls`, `clear`, `uname`, `pwd`, `touch`, `rm`, `top`, `free`.
- [x] Поддержка сигналов прерывания: `Ctrl+C` прерывает дочерний процесс, не роняя ядро и шелл.
- [x] Интернационализация Userland (`libwunix::i18n`): автоопределение языка ядра через `/etc/locale` и параметры cmdline (`lang=ru`/`lang=en`).

### Фаза 8: Драйверы VirtIO (Полный стек виртуализации QEMU)
- [x] Сканирование шины PCI / PCIe (`pci::scan()`, опрос конфигурационного пространства, Vendor ID, Device ID, BAR).
- [x] Инфраструктура очередей VirtIO (Virtqueue: Split Virtqueue дескрипторы, кольца Available и Used).
- [x] Блочный накопитель `virtio-blk` (чтение/запись секторов LBA, постоянное дисковое хранилище в QEMU).
- [x] Сетевой адаптер `virtio-net` (приём/передача Ethernet-фреймов, интеграция с сетевым стеком).
- [x] Устройства ввода `virtio-input` (планшет и мышь с абсолютными координатами курсора).
- [x] Видеоадаптер `virtio-gpu` (аппаратное переключение видеорежимов, 2D ускорение).

### Фаза 9: Сетевой стек на Rust и дисковые инструменты

  - [x] Системные вызовы `SYS_MMAP` (9) и `SYS_MUNMAP` (11) для аллокации динамической памяти процессов (VMA, demand paging арен).
  - [x] Системный вызов `SYS_ARCH_PRCTL` (158) для установки регистра `FS_BASE` (TLS потоков) с сохранением/восстановлением при планировании.

  - [x] Системные вызовы энтропии и сигналов: `SYS_GETRANDOM` (318), `SYS_RT_SIGACTION` (13), `SYS_RT_SIGPROCMASK` (14), `SYS_SIGALTSTACK` (131).

  - [x] Полная верификация системных вызовов рантайма: успешное выполнение комплексных тестов на многопоточность/каналы, аллокатор/GC и неблокирующий I/O/таймеры.
- [x] Сетевой стек ядра на Rust (`smoltcp`) и интерфейс BSD-сокетов:
  - [x] Интеграция драйвера `virtio-net` со стеком `smoltcp` (обработка Ethernet фреймов в ядре, кольцевые RX/TX буферы).
  - [x] Поддержка сетевых системных вызовов Linux: `SYS_SOCKET` (41), `SYS_CONNECT` (42), `SYS_SENDTO` (44), `SYS_RECVFROM` (45), `SYS_BIND` (49), `SYS_LISTEN` (50), `SYS_ACCEPT` (43).

- [x] Набор сетевых утилит в базовом образе (Userland на Rust):
  - [x] Утилита `ping`: отправка ICMP Echo-запросов и замер задержки (RTT).
  - [x] Утилита `curl` / `wget`: выполнение HTTP GET запросов и загрузка файлов по сети.
  - [x] Утилита `ip`: отображение сетевых интерфейсов, назначение IP-адресов и маршрутов шлюза по умолчанию.
  - [x] Утилита `ss` / `netstat`: просмотр открытых сокетов и сетевых соединений.
- [x] Набор дисковых утилит и файловые системы:
  - [x] Интеграция блочного драйвера `virtio-blk` с подсистемой устройств ядра (`/dev/vda`).

- [x] Системные и диагностические утилиты для работы с железом и справкой:
  - [x] Утилиты `lspci`, `lshw`, `lsdev`, `lsmod`, `modinfo`, `hwclock`, `fbset`.
  - [x] Утилита `man` с оффлайн-страницами документации (`/usr/share/man/ru/man1/`, `/usr/share/man/en/man1/`).

### Фаза 10: Пользователи и управление доступом (Multi-User & Security)
- [x] Модель идентификации процессов и пользователей:

  - [x] Привилегированный суперпользователь `root` (UID 0, GID 0) с начальной сессией по умолчанию в `/root` без пароля.
  - [x] Системные вызовы учетных записей: `SYS_GETUID` (102), `SYS_SETUID` (105), `SYS_GETGID` (104), `SYS_SETGID` (106), `SYS_GETEUID` (107), `SYS_GETEGID` (108), `SYS_UMASK` (95).
