# Каталог программ пользователя Wunix

В этом разделе приведен подробный справочник по всем пользовательским утилитам, входящим в стандартный состав дистрибутива Wunix.

---

## 1. Работа с файлами и каталогами

### `cat` — просмотр и объединение файлов
Выводит содержимое одного или нескольких файлов в стандартный поток вывода.
* **Синтаксис**: `cat [ФАЙЛ...]`
* **Примеры**:
  ```bash
  cat /etc/hostname
  cat file1.txt file2.txt > combined.txt
  ```

### `ls` — просмотр содержимого директорий
Отображает файлы и каталоги с поддержкой подробного вывода, скрытых файлов и цветовой разметки.
* **Синтаксис**: `ls [ОПЦИИ] [ПУТЬ...]`
* **Ключевые флаги**:
  * `-l` — подробный список (права доступа, владелец, группа, размер, дата изменения).
  * `-a` — показывать скрытые файлы (начинающиеся с точки `.`).
  * `-h` — человекочитаемый размер файлов (K, M, G).
* **Примеры**:
  ```bash
  ls -la
  ls -lh /bin
  ```

### `mkdir` — создание каталогов
Создает одну или несколько директорий.
* **Синтаксис**: `mkdir [ОПЦИИ] ДИРЕКТОРИЯ...`
* **Ключевые флаги**:
  * `-p` — создавать родительские каталоги при их отсутствии без ошибки.
* **Примеры**:
  ```bash
  mkdir projects
  mkdir -p docs/2026/november
  ```

### `rmdir` — удаление пустых каталогов
Удаляет пустые каталоги.
* **Синтаксис**: `rmdir ДИРЕКТОРИЯ...`
* **Пример**:
  ```bash
  rmdir old_folder
  ```

### `rm` — удаление файлов
Удаляет указанные файлы из файловой системы.
* **Синтаксис**: `rm [ОПЦИИ] ФАЙЛ...`
* **Ключевые флаги**:
  * `-f` — принудительное удаление без вывода предупреждений.
  * `-r` — рекурсивное удаление каталогов и их содержимого.
* **Примеры**:
  ```bash
  rm temp.log
  rm -rf old_build/
  ```

### `touch` — создание пустого файла / обновление времени
Создает пустой файл, если он не существовал, либо обновляет метку времени модификации.
* **Синтаксис**: `touch ФАЙЛ...`
* **Пример**:
  ```bash
  touch notes.txt
  ```

### `ln` — создание ссылок
Создает жесткие (hard link) или символические (symlink) ссылки на файлы и каталоги.
* **Синтаксис**: `ln [-s] ЦЕЛЬ ИМЯ_ССЫЛКИ`
* **Ключевые флаги**:
  * `-s` — создать символическую ссылку (по умолчанию создается жесткая).
* **Примеры**:
  ```bash
  ln -s /win/drives/c/Windows win_dir
  ln file.txt hardlink.txt
  ```

### `readlink` — чтение значения символической ссылки
Показывает, на какой целевой путь указывает символическая ссылка.
* **Синтаксис**: `readlink ССЫЛКА`
* **Пример**:
  ```bash
  readlink /win/drives/c/Users/user
  # Вывод: /home/user
  ```

### `pwd` — печать текущей рабочей директории
Выводит абсолютный путь к текущему каталогу.
* **Синтаксис**: `pwd`

## 2. Текстовые операции и вывод

### `echo` — печать текста
Выводит переданные аргументы в консоль.
* **Синтаксис**: `echo [СТРОКА...]`
* **Ключевые флаги**:
  * `-n` — не печатать завершающий перевод строки.
* **Примеры**:
  ```bash
  echo "Привет мир"
  echo $PATH
  ```

### `clear` — очистка экрана
Очищает экран виртуального терминала и возвращает курсор в левый верхний угол.
* **Синтаксис**: `clear`

## 3. Сеть и коммуникации

### `curl` — HTTP-клиент
Загружает данные с веб-серверов по протоколу HTTP/1.1 через стек TCP/IP ядра Wunix.
* **Синтаксис**: `curl [ОПЦИИ] URL`
* **Ключевые флаги**:
  * `-o ФАЙЛ` — сохранить ответ сервера в указанный файл.
  * `-v` — подробный вывод заголовков HTTP-запроса и ответа.
* **Примеры**:
  ```bash
  curl http://192.168.1.1/index.html
  curl -o page.html http://example.com/
  ```

### `host` — DNS резолвер
Выполняет запрос к DNS-серверу для преобразования доменного имени в IPv4-адрес.
* **Синтаксис**: `host ДОМЕННОЕ_ИМЯ`
* **Пример**:
  ```bash
  host example.com
  # Вывод: example.com has address 93.184.216.34
  ```

## 4. Мониторинг и системная информация

### `top` — монитор процессов в реальном времени
Отображает динамический список выполняющихся потоков, загрузку CPU, использование памяти и системное время работы (uptime).
* **Синтаксис**: `top`
* **Управление**:
  * `q` — выход из утилиты.

### `free` — сводка использования оперативной памяти
Отображает общий объем физической памяти, объем занятой памяти ядром и процессами, а также размер свободных фреймов.
* **Синтаксис**: `free [-m | -h]`
* **Примеры**:
  ```bash
  free -h
  ```

### `time` — хронометраж выполнения программ
Запускает указанную команду и измеряет время ее работы (реальное время wall-clock, время в пространстве пользователя и ядре).
* **Синтаксис**: `time КОМАНДА [АРГУМЕНТЫ...]`
* **Пример**:
  ```bash
  time ls -la /usr/share/man
  ```

### `uname` — информация об операционной системе и ядре
Печатает сведения об архитектуре процессора, версии ядра Wunix и имени хоста.
* **Синтаксис**: `uname [-a]`
* **Примеры**:
  ```bash
  uname -a
  # Вывод: Wunix wunix 0.1.0-alpha #1 Mon Nov 2 2026 x86_64 Wunix/Rust
  ```

### `lshw` — инвентаризация оборудования
Отображает полную сводку об архитектуре CPU, объеме RAM, шинах PCI, контроллерах VirtIO и видеоадаптерах.
* **Синтаксис**: `lshw`

### `lspci` — список устройств шины PCI
Сканирует конфигурационное пространство шины PCI и выводит обнаруженные устройства (Vendor ID, Device ID, класс устройства).
* **Синтаксис**: `lspci [-v]`

### `lsdev` — список устройств ядра
Отображает зарегистрированные в менеджере устройств ядра символьные и блочные девайсы.
* **Синтаксис**: `lsdev`

### `lsmod` и `modinfo` — модули и подсистемы ядра
* `lsmod` — список активных подсистем ядра.
* `modinfo ИМЯ_МОДУЛЯ` — просмотр информации об авторе, лицензии и описании драйвера.

## 5. Дата, время и экран

### `date` — текущая дата и системное время
Отображает текущее время и дату в формате UTC или локального часового пояса.
* **Синтаксис**: `date`

### `hwclock` — чтение аппаратных часов RTC
Читает показания микросхемы часов реального времени CMOS MC146818.
* **Синтаксис**: `hwclock`

### `fbset` — разрешение и параметры фреймбуфера
Показывает текущее разрешение экрана (например, 1024x768x32bpp) и параметры видеопамяти Limine Framebuffer.
* **Синтаксис**: `fbset`

## 6. Пользователи и безопасность

### `whoami` и `id`
* `whoami` — выводит имя активного пользователя.
* `id` — выводит детальные идентификаторы UID, GID и группы.

### `passwd` — смена пароля
Позволяет изменить пароль учетной записи. Обычный пользователь может сменить только свой пароль (потребуется ввести старый пароль).
* **Синтаксис**: `passwd`

### `su` — переключение пользователя
Запускает новую оболочку от имени другого пользователя (по умолчанию `root`).
* **Синтаксис**: `su [ИМЯ_ПОЛЬЗОВАТЕЛЯ]`
* **Пример**:
  ```bash
  su root
  ```
