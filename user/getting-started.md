# Быстрый старт с Wunix

В этом руководстве описаны первые шаги после запуска операционной системы Wunix.

---

## 1. Загрузка системы

При старте с компакт-диска или загрузочного накопителя Wunix встречает вас загрузочным меню **Limine Bootloader**:

```text
==================================================
                 WUNIX BOOT MENU
==================================================
 1. Wunix Live Session (RAM-диск)
 2. Wunix Installer (Установка на диск)
 3. Wunix Live (English Locale)
==================================================
```

* **Wunix Live Session** — загрузка полноценной рабочей среды непосредственно в оперативную память. Ваши диски не затрагиваются, система готова к экспериментам за секунды.
* **Wunix Installer** — запуск псевдографического инсталлятора `winstall` для разметки жесткого диска и постоянной установки ОС.

Выберите пункт `1` (или нажмите Enter). Ядро инициализирует оборудование, примонтирует корневую файловую систему и передаст управление процессу инициализации `init`.

---

## 2. Экран входа в систему (`login`)

После завершения загрузки драйверов на экране появится приглашение входа:

```text
Wunix OS 0.1.0-alpha (x86_64) - tty1
wunix login: 
```

### Стандартные учетные записи:
* **Обычный пользователь**: логин `user`, пароль `user`.
* **Суперпользователь (root)**: логин `root`, пароль `root`.

> [!NOTE]  
> При вводе пароля на экране печатаются звездочки `*` для защиты от подглядывания.  
> Клавиша Backspace корректно стирает введенные символы и звездочки на экране.

После успешной авторизации запускается интерактивная командная оболочка **WSH (Wunix Shell)**:

```text
user@wunix:~$ 
```

## 3. Первые команды в системе

### Где я нахожусь?
Узнать текущую рабочую директорию:
```bash
pwd
# Вывод: /home/user
```

### Что находится в каталоге?
Посмотреть список файлов и папок:
```bash
ls -la
```

### Кто текущий пользователь?
Посмотреть имя пользователя и идентификаторы UID/GID:
```bash
whoami
# Вывод: user

id
# Вывод: uid=1000(user) gid=1000(user) groups=1000(user),27(sudo)
```

### Создание первого файла и просмотр
```bash
echo "Привет, Wunix!" > hello.txt
cat hello.txt
# Вывод: Привет, Wunix!
```

### Использование диска C:\
Попробуйте обратиться к своему каталогу через путь Windows:
```bash
ls "C:\Users\user"
# Вы увидите созданный файл hello.txt
```

## 4. Справочная система (`man`)

В Wunix встроена автономная справочная система. Чтобы получить подробную справку по любой утилите, выполните:
```bash
man ls
man cat
man curl
```
Справка автоматически отображается на языке вашей текущей локали (русский по умолчанию, либо английский).

---

## 5. Завершение сеанса или работы

* Выйти из текущей оболочки:
  ```bash
  exit
  ```
  После выхода снова появится окно `login`.
* Перезагрузить компьютер (требуются права root или `sudo`):
  ```bash
  sudo reboot
  ```
* Выключить питание компьютера:
  ```bash
  sudo shutdown -h now
  ```
