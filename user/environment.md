# Пользовательское окружение и оболочка WSH

Интерактивная командная оболочка **WSH (Wunix Shell)** является основным интерфейсом взаимодействия пользователя с операционной системой Wunix.

---

## 1. Возможности командной оболочки WSH

### Синтаксис и запуск программ
* Если команда содержит слеш (`/bin/ls` или `./my_script`), WSH запускает бинарник напрямую по указанному пути.
* Если команда указана без слеша (`ls`), WSH последовательно ищет исполняемый файл в каталогах, перечисленных в переменной среды `$PATH` (по умолчанию: `/bin:/usr/bin`).

### Конвейеры (Pipes `|`)
WSH поддерживает связывание стандартного вывода одной программы со стандартным вводом другой с помощью символа `|`:
```bash
ls -la /bin | cat
cat /etc/passwd | top
```
Ядро организует IPC через безаллокационный кольцевой буфер системного вызова `sys_pipe2`.

### Перенаправление ввода и вывода (`>`, `>>`, `<`)
* `>` — перенаправить вывод в файл с перезаписью:
  ```bash
  echo "Тестовая запись" > file.txt
  ```
* `>>` — перенаправить вывод в файл с дозаписью в конец:
  ```bash
  echo "Вторая строка" >> file.txt
  ```
* `<` — перенаправить ввод из файла:
  ```bash
  cat < file.txt
  ```

## 2. Переменные среды окружения

Каждый процесс в Wunix наследует блок переменных окружения `environ`.

| Переменная | Назначение | Пример значения |
|---|---|---|
| `PATH` | Список каталогов поиска исполняемых файлов | `/bin:/usr/bin` |
| `USER` | Имя текущего пользователя | `user` |
| `HOME` | Домашний каталог пользователя | `/home/user` |
| `SHELL`| Путь к текущей оболочке | `/bin/wsh` |
| `TERM` | Тип терминала | `wunix-console` |
| `LANG` | Языковой стандарт и локаль | `ru_RU.UTF-8` или `en_US.UTF-8` |

### Просмотр переменных
Вывести значение конкретной переменной:
```bash
echo $USER
echo $HOME
echo $PATH
```

## 3. Горячие клавиши и управление терминалом

Консольный драйвер ядра и WSH поддерживают стандартные комбинации клавиш:

* **Ctrl + C** (`SIGINT`) — прерывание выполнения текущей программы и возврат в командную строку.
* **Ctrl + D** (`EOF`) — закрытие стандартного ввода или выход из оболочки `exit`.
* **Ctrl + L** — быстрая очистка экрана (аналог команды `clear`).
* **Backspace** — удаление предыдущего символа с корректным стиранием на экране.
* **Стрелки Вверх / Вниз** — навигация по истории введенных команд.
* **Стрелки Влево / Вправо** — перемещение курсора внутри текущей строки ввода.
* **Home / End** — мгновенный переход в начало или конец строки ввода.

## 4. Переключение языка системы (Локализация)

Wunix поддерживает мультиязычность "из коробки" как на уровне ядра, так и в пользовательских утилитах.

### Текущий язык
Текущий язык определяется содержимым файла конфигурации `/etc/locale`:
* `ru` — русский язык.
* `en` — английский язык.

### Смена языка в работающей системе:
Для переключения языка на английский:
```bash
sudo echo "en" > /etc/locale
```
Для переключения языка на русский:
```bash
sudo echo "ru" > /etc/locale
```

Все системные утилиты, использующие вызов `libwunix::i18n::t()`, и man-руководства мгновенно переключатся на выбранный язык без необходимости перезагрузки системы.
