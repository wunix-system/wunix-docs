# Руководство пользователя Wunix

Добро пожаловать в руководство пользователя операционной системы **Wunix**!  
Wunix создана для того, чтобы предоставить вам производительную, безопасную и предсказуемую рабочую среду, построенную на стандартах и философии UNIX.

---

## 1. Концепция окружения

Wunix предоставляет классическую, удобную командную строку и стандартное дерево каталогов POSIX/UNIX.

### Единое пространство файлов
В системе существует единое корневое дерево `/`. Все устройства, постоянные накопители и виртуальные каталоги примонтированы внутри него:
* `/bin` — исполняемые программы пользователя и системные утилиты (`cat`, `ls`, `ping`, `wsh`).
* `/home/<имя_пользователя>` — домашний каталог пользователя, где хранятся личные файлы, настройки и документы.
* `/root` — домашний каталог суперпользователя `root`.
* `/tmp` — временный каталог с общим доступом для процессов.
* `/dev` — виртуальные файлы устройств (терминалы `tty`, блочные устройства дисков, `/dev/null`, `/dev/zero`).
* `/proc` и `/sys` — псевдофайловые системы ядра, предоставляющие динамическую информацию о процессах, памяти и оборудовании.
* `/mnt` — точки монтирования постоянных дисковых накопителей (FAT32).

### Перспективы: Подсистема совместимости (win-init)
В ядре Wunix заложена архитектурная возможность подключения дополнительных исполнительных сред. В будущих версиях запланирована утилита `win-init`, которая по запросу пользователя сможет активировать слой совместимости Windows NT (монтирование ветки `/win`, структуру реестра и трансляцию путей Win32). По умолчанию Wunix работает исключительно как чистая UNIX-система.
