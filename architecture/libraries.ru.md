# Системные библиотеки и экосистема рантайма Wunix

Операционная система Wunix построена на многослойной структуре библиотек: от низкоуровневых зависимостей ядра (`Kernel Crates`) и внутриядерной vDSO-страницы (`Syslib`) до легковесной базовой библиотеки пользовательского режима (`libwunix`).

---

## 1. Системная библиотека пользовательского режима (`libwunix`)

Библиотека `libwunix` ([`wunix/libs/libwunix/`](file:///home/valdis/my-os/wunix/libs/libwunix)) является фундаментальным `no_std` фундаментом для всех консольных утилит и сервисов пространства пользователя (Ring 3).

```
libs/libwunix/src/
├── lib.rs            # Прямые ассемблерные сисколл-шлюзы syscall0..syscall6, stdio, базовый I/O
├── syslib.rs         # Интерфейс связи с vDSO ядра (быстрые строковые функции и трамплины)
├── errno.rs          # Типизированное перечисление ошибок POSIX (Errno) и конвертер check()
├── i18n.rs           # Локализация пользовательских программ (чтение /etc/locale, функция t())
├── env.rs            # Парсер переменных окружения процесса (getenv, итератор environ)
├── fmt.rs            # Безаллокационное форматирование чисел в текст (utoa, itoa, utoa_hex)
├── str_utils.rs      # Низкоуровневые операции с C-строками (strlen, strchr, starts_with_ci, strtoul)
├── time.rs           # Разбор времени Epoch на структуру DateTime с учетом високосных лет
└── registry.rs       # Клиент доступа к виртуальному реестру Windows NT (/win/registry/)
```

### 1.1. Модули и ответственность
| Модуль | Расположение | Назначение |
|:---|:---|:---|
| `lib.rs` | `libs/libwunix/src/lib.rs` | Сисколл-трамплины `syscall0`..`syscall6`, реализация макросов `print!`, `println!`, `eprintln!`, дескрипторы `STDIN_FILENO`, `STDOUT_FILENO`, `STDERR_FILENO`, функции `open`, `read`, `write`, `close`, `lseek`, `stat`, `getdents64`, `mount`, `umount2`, `system_poweroff`, `system_reboot`. |
| `syslib.rs` | `libs/libwunix/src/syslib.rs` | Предоставляет безопасный доступ к виртуальной библиотеке vDSO ядра: быстрые функции без перехода в режим ядра. |
| `errno.rs` | `libs/libwunix/src/errno.rs` | Перечисление ошибок `Errno` (`EPERM`, `ENOENT`, `EACCES`, `EINVAL` и др.) и функция `check(res)` для преобразования кодов в `Result<u64, Errno>`. |
| `i18n.rs` | `libs/libwunix/src/i18n.rs` | Считывает системную локаль из `/etc/locale` и предоставляет функцию перевода `t(ru, en)` с нулевыми накладными расходами. |
| `env.rs` | `libs/libwunix/src/env.rs` | Управление переменными среды (`envp`): быстрый безаллокационный поиск `getenv(key)` и итератор по всем переменным `environ()`. |
| `fmt.rs` | `libs/libwunix/src/fmt.rs` | Форматирование чисел в статические стековые буферы без кучи: `utoa` (беззнаковые), `itoa` (знаковые), `utoa_hex` (HEX). |
| `str_utils.rs`| `libs/libwunix/src/str_utils.rs` | Утилиты для сырых строк: `strlen`, `memcmp`, `strchr`, поиск без учета регистра `starts_with_ci`, парсинг целых чисел `strtoul`. |
| `time.rs` | `libs/libwunix/src/time.rs` | Работа со временем (`Timespec`, `DateTime`): преобразование миллисекунд Unix Epoch в день, месяц, год, часы, минуты и секунды. |
| `registry.rs` | `libs/libwunix/src/registry.rs` | Клиент реестра Windows NT для чтения строковых и числовых параметров (`reg_query_sz`, `reg_query_dword`) из `/win/registry/`. |

## 2. Виртуальная разделяемая библиотека ядра (vDSO / Syslib)

В адресное пространство каждого запускаемого процесса Ring 3 по фиксированному виртуальному адресу **`0x0000_7FFF_FFFF_0000`** ядро проецирует страницу **Syslib / vDSO** ([`kernel/src/task/syslib.rs`](file:///home/valdis/my-os/wunix/kernel/src/task/syslib.rs)).

```
Адрес в процессе: 0x0000_7FFF_FFFF_0000
┌────────────────────────────────────────────────────────┐
│               Структура SyslibSharedInfo               │
│ - Магическое число: 'WUNIXLIB' (8 байт)                 │
│ - Версия ABI: 1                                        │
│ - Системная частота таймера: 100 Гц                    │
│ - Время старта ядра (Boot Timestamp в мс)              │
│ - Таблица экспортируемых символов и смещений           │
├────────────────────────────────────────────────────────┤
│     Адрес: 0x0000_7FFF_FFFF_1000 (Код vDSO)            │
│ 1. Встроенный strlen (17 байт ассемблера x86_64)       │
│ 2. Встроенный memcpy (инструкция rep movsb)            │
│ 3. Встроенный memset (инструкция rep stosb)            │
│ 4. Готовые трамплины сисколлов Linux (read, write...)  │
│ 5. Готовые трамплины NT ABI (NtReadFile, NtClose...)   │
└────────────────────────────────────────────────────────┘
```

### Преимущества vDSO:
- **Zero-Syscall операции**: Функции `strlen`, `memcpy`, `memset` исполняются на полной скорости процессора в Ring 3 без переключения контекста и без затрат на переход в режим ядра.
- **Отказоустойчивость**: Процесс не зависит от динамического компоновщика (ld.so) при выполнении фундаментальных строковых операций.

## 3. Зависимости и крейты ядра (Kernel Crates)

Низкоуровневые компоненты ядра Wunix Core скомпонованы с использованием проверенных и легковесных `no_std` крейтов:

| Крейт | Версия | Область применения | Назначение |
|:---|:---:|:---|:---|
| `limine` | `0.6.5` | `arch/x86_64/` | Протокол начальной загрузки: HHDM, карта памяти, фреймбуфер и модули initramfs. |
| `x86_64` | `0.15` | `arch/`, `memory/` | Архитектурные типы: регистры CR0/CR3/CR4, 4-уровневые таблицы страниц, GDT, IDT, TSS. |
| `spin` | `0.9` | `sync/`, `fs/`, `task/` | Примитивы синхронизации в `no_std`: спинлоки `Mutex`, `RwLock` и однократная инициализация `Once`. |
| `smoltcp` | `0.11` | `net/` | Автономный сетевой стек ядра: Ethernet II, ARP, IPv4, ICMP, UDP, TCP со скользящим окном. |
| `uart_16550` | `0.3` | `drivers/serial.rs` | Драйвер последовательного порта COM1 (`0x3F8`): вывод логов ядра в хост-консоль QEMU. |
| `pic8259` | `0.11` | `arch/x86_64/` | Контроллер аппаратных прерываний 8259 PIC (ремап векторов на `32..47`). |
| `linked_list_allocator` | `0.10.5` | `memory/heap.rs` | Аллокатор динамической кучи ядра: обеспечивает работу `extern crate alloc` (`Box`, `Vec`, `String`). |
| `pc-keyboard` | `0.7` | `drivers/keyboard.rs` | Декодирование скан-кодов PS/2 с поддержкой модификаторов Shift, Alt, Ctrl, CapsLock. |
| `kernel::i18n` | *Внутр.* | `i18n/mod.rs` | Внутренний каталог локализации ядра: ключи сообщений `MsgKey`, макросы `tr!` и `t!`. |

Библиотеки и SDK пользовательского режима, запланированные к разработке в рамках развития экосистемы Wunix:

1. **`libwui` (Wunix UI SDK)**: Графический тулкит для построения оконных приложений. Включает декларативную компоновку (Layout), систему событий, виджеты (кнопки, поля ввода, списки) и аппаратный рендеринг через `virtio-gpu`.
2. **`libwunix-c` (`libc.so`)**: Стандартная библиотека языка C (заголовки `stdio.h`, `stdlib.h`, `string.h`, `unistd.h`, аллокатор `malloc`) для портирования классического UNIX-софта.
3. **Rust Standard Library (`std`)**: Нативная поддержка официального Rust `std` (компиляция под таргет `x86_64-unknown-wunix`) с поддержкой `std::fs`, `std::net`, `std::thread`, `std::sync`.
4. **`libwsh` (Shell SDK)**: Библиотека командного интерпретатора: лексический разбор, построение графа пайплайнов, история команд и интеллектуальное автодополнение по Tab.
5. **`libwcrypto`**: Криптографические алгоритмы (SHA-256, SHA-512, Ed25519, ChaCha20) для верификации цифровых подписей пакетов и работы с хэшами `/etc/shadow`.
6. **`libwpm` / `libwsp`**: Движок системы управления пакетами: чтение манифестов `package.toml`, верификация зависимостей, атомарная установка и контрольные точки отката.
7. **`ntdll.dll` / `libntemu`**: Слой эмуляции пользовательского режима Win32 (`kernel32.dll`, `advapi32.dll`) поверх нативных системных вызовов Windows NT ABI ядра Wunix.
