# Руководство разработчика Wunix

Добро пожаловать в руководство разработчика операционной системы **Wunix**!  
Этот раздел предназначен для инженеров, желающих изучить внутреннее устройство системы, собрать ядро из исходного кода, разработать собственные системные утилиты или драйверы оборудования.

---

## 1. Философия разработки

Wunix создается по строгим стандартам промышленной программной инженерии:
* **Безопасность памяти (Memory Safety)**: Ядро написано на языке **Rust** без использования стандартной библиотеки (`#![no_std]`). Вся работа с сырыми указателями и регистрами процессора жестко локализована в модулях `arch/` и абстрагирована в безопасные RAII-структуры.
* **Принцип единой ответственности (SRP)**: Каждая подсистема, структура и функция выполняет строго одну задачу. Монолитные файлы свыше 250 строк декомпозируются.
* **Инженерная дисциплина (`ub-mode`)**: Следование принципам Дядюшки Боба (Uncle Bob), разработка через тестирование (TDD), строгий контроль цикломатической сложности.
* **Нативная мультиязычность**: Система изначально проектируется с поддержкой локализации (RU/EN) на уровне ядра и пользовательского пространства.

1. **[Сборка и запуск системы](building.md)**  
   Подготовка сборочного окружения (Rust nightly, QEMU, xorriso), работа со сборочным скриптом `tools/run.sh`, флаги компиляции и эмуляция.

   Написание `no_std` пользовательских утилит, использование системной библиотеки `libwunix`, безаллокационный вывод и работа с сисколлами.

   Стандарты чистого кода, SRP, осмысленные комментарии в коде, правила локализации и формат Git-коммитов.
