# Устройство и архитектурная структура ядра

Исходный код ядра операционной системы Wunix расположен в каталоге [`wunix/kernel/src/`](file:///home/valdis/my-os/wunix/kernel/src/).  
Архитектура строго подчинена принципу единой ответственности (SRP) и разделена на изолированные функциональные домены.

---

## 1. Карта каталогов ядра

```
kernel/src/
├── arch/                     # Низкоуровневый железо-зависимый код (архитектура CPU)
│   └── x86_64/
│       ├── mod.rs            # Точка входа платформенной инициализации
│       ├── gdt.rs            # GDT, TSS и аварийные стеки исключений (IST)
│       ├── idt.rs            # Таблица векторов прерываний и обработчики CPU
│       ├── interrupts.rs     # Обработчики прерываний и исключений
│       ├── cpu.rs            # Данные процессора (CPUID, регистры)
│       ├── timer.rs          # Системный таймер PIT 8254
│       └── syscall.rs        # Ассемблерный вход MSR LSTAR системных вызовов
├── drivers/                  # Драйверы оборудования
│   ├── mod.rs                # Фасад подсистемы оборудования
│   ├── traits.rs             # Унифицированные типажи (BlockDevice, NetDevice)
│   ├── manager.rs            # DeviceManager, шинный PCI-скан и VirtIO-проб
│   ├── registry.rs           # Реестр доступных драйверов ядра
│   ├── display.rs            # Графический вывод (Limine Framebuffer, ANSI/VT100)
│   ├── font.rs               # Растровый моноширинный шрифт 8x16 (ASCII + кириллица)
│   ├── serial.rs             # COM-порт (UART 16550)
│   ├── keyboard.rs           # Драйвер PS/2 клавиатуры (раскладки EN/RU, Alt+Shift, Ctrl+C)
│   ├── rtc.rs                # Часы реального времени CMOS MC146818
│   ├── pci/                  # Подсистема шины PCI (конфигурация, сканирование)
│   └── virtio/               # Драйверы VirtIO (blk, net, gpu, input, pci transport)
├── fs/                       # Виртуальная файловая система (VFS)
│   ├── mod.rs                # Инициализация VFS и публичный фасад
│   ├── vfs.rs                # Базовые трейты: Inode, FileSystem
│   ├── fd.rs                 # Таблица файловых дескрипторов (FD table)
│   ├── handle.rs             # Типажи и реализации FileHandle (файлы, stdio, пайпы)
│   ├── ops.rs                # Файловые операции (resolve_path, open, read, write)
│   ├── procfs.rs             # Генерация динамических узлов /proc и /sys
│   ├── ramfs.rs              # Корневая память initramfs
│   ├── fat.rs                # Драйвер файловой системы FAT32 (LFN)
│   └── tar.rs                # Парсер архивов initramfs.tar
├── task/                     # Процессы, потоки, планировщик и системные вызовы
│   ├── mod.rs                # Инициализация подсистемы задач
│   ├── scheduler.rs          # Планировщик потоков (Round-Robin, квант 50мс)
│   ├── context.rs            # Переключение контекста процессора (asm context_switch)
│   ├── thread.rs             # Структура Task/Thread
│   ├── elf.rs                # Загрузчик бинарников ELF64 в Ring 3
│   └── syscall/              # Модульный диспетчер системных вызовов (SRP)
│       ├── mod.rs            # Роутер вызовов и валидация Ring 3 указателей
│       ├── fs.rs             # Системные вызовы VFS (read, write, open, close, stat...)
│       ├── mem.rs            # Вызовы виртуальной памяти (mmap, munmap, brk...)
│       ├── proc.rs           # Вызовы управления процессами (clone, execve, exit...)
│       ├── net.rs            # Вызовы сокетов (socket, connect, sendto, recvfrom...)
│       └── ipc.rs            # Вызовы IPC (pipe2, epoll, eventfd, mount...)
├── memory/                   # Подсистема управления памятью
│   ├── mod.rs                # Инициализация всей памяти ядра
│   ├── frame.rs              # Физический аллокатор страниц (4KiB фреймы)
│   ├── paging.rs             # Виртуальная память, маппинг и трансляция страниц
│   ├── process.rs            # Таблицы страниц пользовательских процессов
│   ├── vma.rs                # Области виртуальной памяти (VMA)
│   └── heap.rs               # Аллокатор кучи ядра (поддержка alloc, Box, Vec)
├── net/                      # Сетевой стек
│   ├── mod.rs                # Инициализация сети
│   ├── socket.rs             # TCP/UDP/IP/ICMP сокеты
│   └── device.rs             # Привязка сетевого устройства к стеку
├── sync/                     # Примитивы синхронизации ядра
│   └── spinlock.rs           # Spinlock, Mutex, Once
├── i18n/                     # Подсистема интернационализации и перевода сообщений
│   └── mod.rs                # Языки (Language), каталог ключей (MsgKey), tr()
├── lib.rs                    # Главная библиотека ядра (init(), halt_loop())
└── main.rs                   # Точка входа (_start) и обработка паник
```

## 2. Ключевые архитектурные правила ядра

1. **Никакого кода железа вне `arch/`**:  
   Код, работающий с ассемблерными инструкциями (`inb`, `outb`, `cli`, `sti`, `lidt`, `lgdt`, `wrmsr`, `rdmsr`), таблицами страниц PML4 или контекстом регистров, обязан быть изолирован внутри каталога `arch/x86_64/`.
2. **Драйверы только через трейты**:  
   Оборудование взаимодействует с ядром через полиморфные интерфейсы `BlockDevice`, `CharDevice`, `NetDevice`. Никакой драйвер не обращается напрямую к структурам планировщика или файловых дескрипторов.
3. **Разделение сисколлов по SRP**:  
   Диспетчер системных вызовов разбит на изолированные предметные области (`fs.rs`, `mem.rs`, `proc.rs`, `net.rs`, `ipc.rs`).
4. **Валидация адресов пользователя**:  
   Любой сырой указатель, приходящий из Ring 3 (`arg1`–`arg6`), перед разыменованием проходит валидацию через `validate_user_buffer()`. Попытка передачи адреса из адресного пространства ядра (`>= 0xFFFF_8000_...`) немедленно пресекается ошибкой `-EFAULT`.
