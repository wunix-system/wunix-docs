# Подсистема интернационализации и локализации Wunix (i18n)

Подсистема `i18n` обеспечивает полноценную многоязычность операционной системы **Wunix** на уровне ядра, драйверов ввода-вывода и системных сообщений.

---

## 1. Архитектурные принципы

В отличие от классических UNIX/Linux систем, где локализация опирается на файлы каталогов GNU gettext (`.mo`), переменные окружения `LC_*` и библиотеки libc, ядро Wunix функционирует в среде без стандартной библиотеки (`no_std`) и до монтирования корневой файловой системы.

Архитектура `i18n` ядра построена на следующих принципах:

1. **Безопасность без блокировок (Lock-Free)**:
   Текущий активный язык хранится в глобальной переменной `AtomicU8` ([`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs)). Это исключает риск взаимных блокировок (deadlocks) и делает вызов функций локализации безопасным даже внутри критических секций и обработчиков аппаратных прерываний (ISR).

2. **Типобезопасный каталог сообщений (`MsgKey` и `tr`)**:
   Все ключевые системные фразы типизированы через перечисление `MsgKey`. Компилятор Rust гарантирует полноту сопоставления (`exhaustive match`): если для нового языка пропущен хотя бы один ключ, проект не соберется.

3. **Быстрый парный хелпер `t(ru, en)`**:
   Для коротких парных меток («включено/выключено», «память/memory») используется инлайн-функция `t`, возвращающая статическую ссылку `'static str`.

4. **Двойная раскладка клавиатуры и переключение по горячим клавишам**:
   Драйвер клавиатуры ([`kernel/src/drivers/keyboard.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/keyboard.rs)) поддерживает одновременную работу с несколькими раскладками (EN / RU) с переключением по `Alt+Shift` и обработкой управляющих комбинаций вроде `Ctrl+C` независимо от текущего языка.

5. **Растровый графический знакогенератор 8×16**:
   Вывод текста на экран ([`kernel/src/drivers/font.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/font.rs)) использует моноширинные матрицы 8×16 с поддержкой ASCII, полной кириллицы (включая `Ё`/`ё` и символ номера `№`) и возможностью легкого расширения под любые национальные алфавиты.

## 2. Параметры командной строки загрузчика (cmdline)

Ядро определяет язык интерфейса при старте на основе параметров, переданных загрузчиком Limine.

### Поддерживаемые флаги:
- `lang=ru` или `locale=ru` — русский язык.
- `lang=en` или `locale=en` — английский язык.
- Сокращенные токены: `ru`, `en`, `de` и т.д.

### Управление через `tools/run.sh`:
Скрипт запуска автоматически конфигурирует образ ISO под выбранный язык:

```bash
# Запуск с русским интерфейсом (по умолчанию):
./tools/run.sh ru
# или:
./tools/run.sh --lang ru

# Запуск с английским интерфейсом:
./tools/run.sh en
# или:
./tools/run.sh --lang en

# Через переменную окружения:
WUNIX_LANG=en ./tools/run.sh
```
