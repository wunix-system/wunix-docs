# Руководство: Как перевести Wunix на свой язык

Данное руководство объясняет, как добавить поддержку нового языка в операционную систему **Wunix**.

Документ специально разделен на две части:
- **[Часть 1: Для переводчиков и гуманитариев](#часть-1-для-переводчиков-и-гуманитариев-без-программирования)** — не требует знания языков программирования. Содержит глоссарий, контекст вывода сообщений на экран, стилевые требования и готовую форму для перевода.
- **[Часть 2: Для инженеров и разработчиков](#часть-2-для-инженеров-и-разработчиков-код-на-rust)** — пошаговая техническая инструкция по внедрению языка в ядро: типизация, исчерпывающее сопоставление (exhaustive match), парсинг параметров командной строки, рисование растровых глифов шрифта 8x16 и добавление раскладки клавиатуры.

---

## Архитектура локализации в двух словах

Локализация в Wunix встроена прямо в ядро (`kernel/src/i18n/`). В отличие от обычных программ для Linux или Windows, где тексты часто подгружаются из внешних файлов `.mo` или `.json`, ядро Wunix работает на «голом железе» (bare-metal) без файловой системы. Поэтому все системные фразы компилируются непосредственно в бинарный образ ядра.

В ядре работают два механизма:
1. **Типизированный каталог ключей (`MsgKey` и функция `tr`)** — используется для всех основных сообщений ОС (баннер готовности, приглашение к вводу, сводка оборудования). Компилятор Rust строго проверяет, чтобы для каждого ключа обязательно присутствовал перевод на все зарегистрированные языки.
2. **Парный инлайн-перевод (`t(ru, en)`)** — быстрый вспомогательный хелпер для коротких парных меток («включено/выключено», «успех/ошибка»).

## Часть 1: Для переводчиков и гуманитариев (без программирования)

Если вы не программируете на Rust, вам не нужно разбираться во внутренностях ядра. Ваша задача — подготовить качественный, лаконичный и контекстно точный перевод системных сообщений.

### 1.1. Контекст системных сообщений и требования к длине

Экран Wunix при загрузке работает в текстовом/графическом режиме с фиксированным размером символов (8×16 пикселей). Длинные фразы, переполняющие строку, могут некрасиво переноситься или сдвигать форматирование колонок.

Ниже приведен список всех текущих системных ключей ядра, их значение и контекст:

| Идентификатор ключа (`MsgKey`) | Русский оригинал | Английский оригинал | Где и когда отображается | Ограничения и рекомендации |
|---|---|---|---|---|
| `SystemReady` | `wunix: система готова к работе` | `wunix: system ready` | Выводится в консоль после завершения инициализации оборудования. | Должно быть кратким системным уведомлением. Избегайте восклицательных знаков и рекламного тона. |
| `PromptInput` | `wunix: введите текст с клавиатуры (переключение раскладки: Alt+Shift)...` | `wunix: type something on keyboard (layout switch: Alt+Shift)...` | Приглашение к вводу внизу экрана перед эхо-режимом консоли. | Сообщает пользователю, что система ожидает ввода, и напоминает горячую клавишу смены раскладки. |
| `InterruptCancel` | `^C (ввод отменен)` | `^C (input cancelled)` | Появляется при нажатии комбинации `Ctrl+C`. | Системный маркер прерывания текущей строки ввода. Традиционно начинается с `^C`. |
| `Cpu` | `процессор` | `cpu` | Метка устройства в сводке автоконфигурации оборудования (dmesg). | Одно слово, желательно строчными (маленькими) буквами для единства со стилем ядра. |
| `Memory` | `память` | `memory` | Метка объема RAM в сводке оборудования. | Одно слово, строчными буквами. |
| `Display` | `экран` | `display` | Метка видеоадаптера / фреймбуфера. | Одно слово, строчными буквами. |
| `Timer` | `таймер` | `timer` | Метка системного таймера (PIT/APIC). | Одно слово, строчными буквами. |
| `Keyboard` | `клавиатура` | `keyboard` | Метка клавиатуры PS/2. | Одно слово, строчными буквами. |
| `Uptime` | `время работы` | `uptime` | Индикатор системного таймера и замера времени. | 1–2 слова. |

### 1.2. Стилевой кодекс Wunix

1. **Лаконичность (UNIX-way)**: Сообщения ядра должны быть строгими, ясными и сдержанными. Никаких «Поздравляем!», «Добро пожаловать в удивительный мир Wunix!» и лишних украшений.
2. **Единообразие регистра**: Названия компонентов оборудования (`cpu`, `память`, `таймер`) пишутся со строчной буквы, системные предложения (`wunix: система готова к работе`) начинаются с префикса подсистемы `wunix:`.
3. **Алфавит и спецсимволы**: Если ваш язык использует диакритические знаки (например, немецкие умлауты `ä`, `ö`, `ü`, `ß` или французские акценты `é`, `à`), обязательно укажите их в заявке на перевод — программистам потребуется отрисовать для них пиксельные глифы в шрифте ядра.

### 1.3. Шаблон для отправки перевода

Чтобы отправить перевод разработчикам Wunix, просто скопируйте блок ниже, вставьте перевод для вашего языка и передайте его в GitHub Issue или Pull Request:

```text
Язык: [Название языка, например: Deutsch / Немецкий]
Код языка (ISO 639-1): [например: de]
Специфические символы алфавита: [например: ä, ö, ü, ß, Ä, Ö, Ü]

ПЕРЕВОД КЛЮЧЕЙ MsgKey:
- SystemReady: "..."
- PromptInput: "..."
- InterruptCancel: "..."
- Cpu: "..."
- Memory: "..."
- Display: "..."
- Timer: "..."
- Keyboard: "..."
- Uptime: "..."

ДОПОЛНИТЕЛЬНЫЕ МЕТКИ:
- Включено / Выключено: "..." / "..."
- Ошибка / Успех: "..." / "..."
```

## Часть 2: Для инженеров и разработчиков (код на Rust)

Если вы внедряете перевод непосредственно в исходный код ядра, следуйте этому пошаговому алгоритму.

В качестве эталонного примера рассмотрим добавление поддержки немецкого языка (**German**, код `de`).

### Шаг 1. Зарегистрировать язык в перечислении `Language`

Откройте файл [`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs). Добавьте новый вариант в перечисление `Language`:

```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
#[repr(u8)]
pub enum Language {
    Russian = 0,
    English = 1,
    German = 2, // Добавленный язык
}
```

> [!NOTE]
> Атрибут `#[repr(u8)]` критически важен: активный язык хранится в глобальной атомарной переменной `AtomicU8`. Это позволяет читать текущий язык без блокировок и взаимных блокировок (deadlocks) даже внутри критических обработчиков прерываний процессора.

Также обновите функцию `current_language()`:

```rust
pub fn current_language() -> Language {
    match CURRENT_LANGUAGE.load(Ordering::Relaxed) {
        0 => Language::Russian,
        2 => Language::German,
        _ => Language::English,
    }
}
```

### Шаг 2. Добавить сопоставление ключей в функцию `tr(key)`

В том же файле [`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs) добавьте ветку для нового языка в функцию `tr()`:

```rust
pub fn tr(key: MsgKey) -> &'static str {
    match current_language() {
        Language::Russian => match key {
            MsgKey::SystemReady => "wunix: система готова к работе",
            MsgKey::PromptInput => "wunix: введите текст с клавиатуры (переключение раскладки: Alt+Shift)...",
            MsgKey::InterruptCancel => "^C (ввод отменен)",
            MsgKey::Cpu => "процессор",
            MsgKey::Memory => "память",
            MsgKey::Display => "экран",
            MsgKey::Timer => "таймер",
            MsgKey::Keyboard => "клавиатура",
            MsgKey::Uptime => "время работы",
        },
        Language::English => match key {
            MsgKey::SystemReady => "wunix: system ready",
            MsgKey::PromptInput => "wunix: type something on keyboard (layout switch: Alt+Shift)...",
            MsgKey::InterruptCancel => "^C (input cancelled)",
            MsgKey::Cpu => "cpu",
            MsgKey::Memory => "memory",
            MsgKey::Display => "display",
            MsgKey::Timer => "timer",
            MsgKey::Keyboard => "keyboard",
            MsgKey::Uptime => "uptime",
        },
        Language::German => match key {
            MsgKey::SystemReady => "wunix: System ist betriebsbereit",
            MsgKey::PromptInput => "wunix: Text eingeben (Layout wechseln: Alt+Shift)...",
            MsgKey::InterruptCancel => "^C (Eingabe abgebrochen)",
            MsgKey::Cpu => "Prozessor",
            MsgKey::Memory => "Speicher",
            MsgKey::Display => "Bildschirm",
            MsgKey::Timer => "Timer",
            MsgKey::Keyboard => "Tastatur",
            MsgKey::Uptime => "Betriebszeit",
        },
    }
}
```

> [!IMPORTANT]
> **Гарантия исчерпывающего сопоставления (Exhaustive Pattern Matching):**
> Категорически запрещено использовать `_ => ...` в сопоставлении ключей внутри `tr()`. Компилятор Rust гарантирует проверку полноты ветвления: если разработчик в будущем добавит новый ключ в `enum MsgKey`, ядро не скомпилируется ни под один язык, пока не будут предоставлены явные строковые переводы для каждого поддерживаемого языка.

### Шаг 3. Добавить обработку параметров загрузчика в `init_from_cmdline`

Ядро Wunix получает параметры командной строки при загрузке через протокол Limine. Чтобы система понимала параметры `lang=de`, `locale=de_DE` или короткий ключ `de`, дополните функцию `init_from_cmdline` в [`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs):

```rust
pub fn init_from_cmdline(cmdline: &str) {
    for token in cmdline.split_whitespace() {
        if let Some((k, v)) = token.split_once('=') {
            if k.eq_ignore_ascii_case("lang") || k.eq_ignore_ascii_case("locale") {
                match v {
                    "ru" | "RU" | "ru_RU" | "russian" => set_language(Language::Russian),
                    "en" | "EN" | "en_US" | "english" => set_language(Language::English),
                    "de" | "DE" | "de_DE" | "german"  => set_language(Language::German),
                    _ => {}
                }
            }
        } else if token.eq_ignore_ascii_case("ru") || token.eq_ignore_ascii_case("russian") {
            set_language(Language::Russian);
        } else if token.eq_ignore_ascii_case("en") || token.eq_ignore_ascii_case("english") {
            set_language(Language::English);
        } else if token.eq_ignore_ascii_case("de") || token.eq_ignore_ascii_case("german") {
            set_language(Language::German);
        }
    }
}
```

Не забудьте дополнить модульный тест `test_init_from_cmdline()` в конце файла, проверяющий переключение на новый язык.

### Шаг 4. Добавить глифы шрифта 8×16 (для спецсимволов)

В Wunix вывод текста на экран осуществляется через растровый знакогенератор [`kernel/src/drivers/font.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/font.rs).

Каждый символ представляет собой массив из 16 байт (`[u8; 16]`), где:
- Каждый байт кодирует 1 горизонтальную строку знакоместа шириной 8 пикселей.
- Старший бит 7 (`0x80`) отвечает за самый левый пиксель.
- Младший бит 0 (`0x01`) отвечает за самый правый пиксель.
- Значение бита `1` — точка цвета текста (Foreground), `0` — точка цвета фона (Background).

#### Пример проектирования символа `'ä'` (строчная a с умлаутом):

```text
Сетка 8x16       Биты        Hex     Пояснение
[0]  ........  00000000    0x00    (пустая строка над символом)
[1]  ........  00000000    0x00
[2]  ..#..#..  00100100    0x24    Точки умлаута (левая и правая)
[3]  ..#..#..  00100100    0x24
[4]  ........  00000000    0x00    (просвет между точками и буквой)
[5]  ..####..  00111100    0x3c    Верхняя перекладина буквы 'a'
[6]  .#....#.  01000010    0x42
[7]  ......#.  00000010    0x02
[8]  ..#####.  00111110    0x3e    Средняя линия
[9]  .#....#.  01000010    0x42
[10] .#....#.  01000010    0x42
[11] ..####.#  00111101    0x3d    Хвостик буквы 'a'
[12] ........  00000000    0x00
[13] ........  00000000    0x00
[14] ........  00000000    0x00
[15] ........  00000000    0x00
```

#### Добавление глифа в код:
В файле [`kernel/src/drivers/font.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/font.rs):

1. Объявите константу растра:
```rust
pub const GLYPH_A_UMLAUT: [u8; 16] = [
    0x00, 0x00, 0x24, 0x24, 0x00, 0x3c, 0x42, 0x02,
    0x3e, 0x42, 0x42, 0x3d, 0x00, 0x00, 0x00, 0x00,
];
```

2. Зарегистрируйте символ в функции `get_glyph(ch: char)`:
```rust
pub fn get_glyph(ch: char) -> Option<&'static [u8; 16]> {
    match ch {
        ' '..='~' => {
            let idx = (ch as u32 - 0x20) as usize;
            Some(&ASCII_GLYPHS[idx])
        }
        'А'..='я' => {
            let idx = (ch as u32 - 0x0410) as usize;
            Some(&CYRILLIC_GLYPHS[idx])
        }
        'Ё' => Some(&GLYPH_YO_UPPER),
        'ё' => Some(&GLYPH_YO_LOWER),
        '№' => Some(&GLYPH_NUMERO),
        'ä' => Some(&GLYPH_A_UMLAUT), // Новый глиф
        _ => None,
    }
}
```

Если символ отсутствует в таблице `get_glyph`, ядро безопасно выведет аккуратную прямоугольную рамку `REPLACEMENT_GLYPH`, предотвращая сбой отображения.

   pub enum Layout {

### Шаг 6. Сборка, запуск и проверка в QEMU

1. **Проверка компиляции ядра:**
   ```bash
   cd wunix/kernel
   cargo check
   ```

2. **Добавление пункта меню в загрузчик `tools/limine.conf`:**
   ```ini
   /Wunix OS (German)
       protocol: limine
       kernel_path: boot():/boot/wunix-kernel
       cmdline: lang=de
   ```

3. **Запуск ядра в QEMU с новым языком:**
   Скрипт `tools/run.sh` собирает образ и передает флаг языка ядру:
   ```bash
   # Прямой запуск с новым языком:
   ./tools/run.sh de
   # или:
   ./tools/run.sh --lang de
   ```

4. **Проверка на экране:**
   - Баннер готовности: `wunix: System ist betriebsbereit`.
   - Сводка железа: `wunix: autoconfiguration: Prozessor, Speicher, Bildschirm, Timer, Tastatur`.
   - Ввод текста и реакция на `Ctrl+C`: `^C (Eingabe abgebrochen)`.
