# Руководство по интернационализации и локализации Wunix (i18n)

Данный документ описывает архитектуру подсистемы локализации ядра Wunix, правила работы с языковыми параметрами загрузки, переключение раскладок клавиатуры, а также пошаговое руководство по добавлению нового языка в операционную систему.

---

## 1. Архитектура подсистемы i18n

Подсистема локализации Wunix реализована в модуле [`kernel/src/i18n/`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs) и обеспечивает:
1. **Типобезопасное хранение активного языка**: перечисление `Language` с атомарным доступом без блокировок (`AtomicU8`), что делает вызов функций перевода безопасным из любого контекста (включая обработчики прерываний).
2. **Типизированный каталог сообщений (`MsgKey` и `tr`)**: все основные системные сообщения имеют уникальный идентификатор в перечислении. Компилятор Rust гарантирует на этапе сборки, что для каждого языка переведены абсолютно все ключи.
3. **Быстрый парный перевод (`t`)**: вспомогательная функция `t(ru, en)` для компактной подстановки в форматированные строки.
4. **Конфигурацию при загрузке**: чтение параметров командной строки от загрузчика Limine через `ExecutableFileRequest`.

## 2. Параметры запуска (cmdline и run.sh)

Ядро определяет язык интерфейса при старте на основе параметров командной строки, переданных загрузчиком.

### 2.1. Прямой запуск через `tools/run.sh`
Скрипт запуска `run.sh` поддерживает указание языка прямо в командной строке и автоматически настраивает образ ISO так, чтобы ядро мгновенно стартовало с нужным языком (без ожидания в меню загрузчика):

```bash
# Запуск на русском языке (по умолчанию)
./tools/run.sh ru
# или:
./tools/run.sh --lang ru

# Запуск на английском языке
./tools/run.sh en
# или:
./tools/run.sh --lang en

# Запуск через переменную окружения
WUNIX_LANG=en ./tools/run.sh
```

### 2.2. Поддерживаемые параметры командной строки ядра
Если ядро запускается вручную или через другую конфигурацию Limine, распознаются следующие флаги cmdline:
- `lang=ru` или `locale=ru` — русский язык сообщений.
- `lang=en` или `locale=en` — английский язык сообщений.
- Сокращенные флаги: `ru`, `en`.

### Настройка в `limine.conf`
Файл [`wunix/tools/limine.conf`](file:///home/valdis/my-os/wunix/tools/limine.conf) содержит меню выбора языка:

```ini
timeout: 3

/Wunix OS (Russian)
    protocol: limine
    kernel_path: boot():/boot/wunix-kernel
    cmdline: lang=ru

/Wunix OS (English)
    protocol: limine
    kernel_path: boot():/boot/wunix-kernel
    cmdline: lang=en
```

> [!TIP]
> В меню загрузчика Limine при старте QEMU можно нажать клавишу `e`, чтобы отредактировать параметры `cmdline` в реальном времени перед запуском ядра.

## 3. Клавиатура и сочетания клавиш

Драйвер клавиатуры ([`kernel/src/drivers/keyboard.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/keyboard.rs)) поддерживает:
1. **Язык клавиатуры по умолчанию**: английская раскладка (`Layout::English`).
2. **Переключение раскладки (RU / EN)**:
   - Горячая клавиша: `Alt + Shift` (или `Ctrl + Shift`).
   - При переключении в консоль выводится индикатор `[RU] ` или `[EN] `.
   - Раскладка ЙЦУКЕН поддерживает полный алфавит из 33 букв (включая `Ё`/`ё`), заглавные буквы через Shift/CapsLock и русскую пунктуацию (`.` и `,` на клавише слэша, `"` на клавише 2, `№` на 3, `:` на 6, `;` на 4, `?` на 7).
3. **Обработка комбинации `Ctrl + C`**:
   - Нажатие `Ctrl + C` генерирует символ ASCII `\x03` (ETX).
   - Консоль прерывает текущий ввод, выводит маркер `^C` с новой строки и повторно отображает приглашение к вводу.
   - Комбинация работает как в английской, так и в русской раскладке.

## 4. Пошаговая инструкция: Как добавить свой язык

Ниже приведен алгоритм добавления нового языка (на примере немецкого языка — German / `de`).

### Шаг 1. Расширить перечисление `Language`
В файле [`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs) добавьте новый вариант в перечисление:

```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
#[repr(u8)]
pub enum Language {
    Russian = 0,
    English = 1,
    German = 2, // Новый язык
}
```

### Шаг 2. Зарегистрировать переводы ключей в `tr()`
В том же файле [`kernel/src/i18n/mod.rs`](file:///home/valdis/my-os/wunix/kernel/src/i18n/mod.rs) добавьте ветку сопоставления для нового языка:

```rust
pub fn tr(key: MsgKey) -> &'static str {
    match current_language() {
        Language::Russian => match key { ... },
        Language::English => match key { ... },
        Language::German => match key {
            MsgKey::SystemReady => "wunix: System ist betriebsbereit",
            MsgKey::PromptInput => "wunix: Text eingeben (Tastaturlayout wechseln: Alt+Shift)...",
            MsgKey::InterruptCancel => "^C (Eingabe abgebrochen)",
            MsgKey::Cpu => "Prozessor",
            MsgKey::Memory => "Speicher",
            MsgKey::Display => "Bildschirm",
            MsgKey::Timer => "Timer",
            MsgKey::Keyboard => "Tastatur",
            MsgKey::Uptime => "Betriebszeit",
        },
    }
}
```

Благодаря проверке исчерпываемости сопоставления (`exhaustive match`), компилятор не позволит забыть перевести ни один ключ.

### Шаг 3. Добавить параметр командной строки
В функции `init_from_cmdline` зарегистрируйте распознавание флагов запуска:

```rust
if k.eq_ignore_ascii_case("lang") || k.eq_ignore_ascii_case("locale") {
    match v {
        "ru" | "RU" | "ru_RU" | "russian" => set_language(Language::Russian),
        "en" | "EN" | "en_US" | "english" => set_language(Language::English),
        "de" | "DE" | "de_DE" | "german"  => set_language(Language::German),
        _ => {}
    }
} else if token.eq_ignore_ascii_case("de") {
    set_language(Language::German);
}
```

### Шаг 4. Добавить глифы шрифта (если алфавит содержит спецсимволы)
Если ваш алфавит использует диакритические знаки или умлауты (`ä`, `ö`, `ü`, `ß`), добавьте 16-байтовые растровые матрицы в [`kernel/src/drivers/font.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/font.rs):

```rust
pub const GLYPH_A_UMLAUT: [u8; 16] = [
    0x00, 0x00, 0x24, 0x24, 0x00, 0x3c, 0x42, 0x42, 
    0x7e, 0x42, 0x42, 0x42, 0x00, 0x00, 0x00, 0x00
];

pub fn get_glyph(ch: char) -> Option<&'static [u8; 16]> {
    match ch {
        ' '..='~' => { ... }
        'А'..='я' => { ... }
        'ä' => Some(&GLYPH_A_UMLAUT),
        // ...
        _ => None,
    }
}
```

### Шаг 5. (Опционально) Добавить национальную раскладку клавиатуры
Если для языка требуется особая раскладка клавиатуры (например, немецкая QWERTZ или французская AZERTY):
1. В [`kernel/src/drivers/keyboard.rs`](file:///home/valdis/my-os/wunix/kernel/src/drivers/keyboard.rs) добавьте вариант в `enum Layout`.
2. Реализуйте функцию сопоставления скан-кодов (по аналогии с `map_russian_keycode`).
3. Подключите обработку в `DualLayout::map_keycode` или сделайте ротацию раскладок через `toggle_layout()`.
