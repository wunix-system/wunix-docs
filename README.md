# Wunix: Документация и техническая база знаний (Wiki)

> **Wunix** — независимая современная UNIX-подобная операционная система с открытым исходным кодом, разрабатываемая с нуля на языке **Rust** для архитектуры x86_64. Система сочетает высокую безопасность управления памятью, строгое следование стандартам UNIX/POSIX, собственную реализацию сетевого стека, гибкую VFS и модульную архитектуру подсистем.

---

## 0. О системе Wunix

### 0.1. Концепция и видение
Цель проекта — создание полноценной, надёжной, расширяемой и самодостаточной операционной системы, пригодной для практического повседневного использования как системными администраторами и инженерами, так и обычными пользователями.

В основе Wunix лежит строгая приверженность стандартам и философии UNIX:
1. **UNIX/POSIX фундамент**: строгая изоляция пользователей (UID/GID), иерархия каталогов (`/bin`, `/etc`, `/home`, `/dev`, `/proc`, `/sys`), модель прав доступа (rwx, suid), пайпы (IPC) и стандартные утилиты CLI.
2. **Безопасность и надежность**: гарантии безопасности памяти языка Rust в ядре (no_std) и Ring 3 пространстве, изолированные адресные пространства процессов, защита стека и разделение привилегий.
3. **Модульность и расширяемость**: ядро спроектировано с возможностью интеграции дополнительных подсистем. В дорожной карте проекта запланирована утилита `win-init`, которая по запросу пользователя сможет инициализировать опциональный слой совместимости с Windows NT (монтирование ветки `/win`, структуру реестра и трансляцию путей Win32).

### 0.2. Ключевые компоненты платформы
Платформа Wunix состоит из логически изолированных слоёв:
* **Wunix Core (Ядро)**: модульное 64-битное монолитное ядро на чистом Rust (Long Mode, higher-half `0xFFFF_8000_...`, протокол Limine). Управляет распределением памяти, процессами, системными вызовами (Linux/POSIX Syscall ABI), драйверами оборудования и виртуальной файловой системой.
* **Wunix Base (Пользовательская среда)**: системная библиотека рантайма `libwunix`, процесс инициализации `init` (PID 1), командная оболочка `wsh` (Wunix Shell) и свыше 50 системных утилит.
* **Wunix Storage & VFS**: единое виртуальное дерево файловой системы, объединяющее оперативную память (`ramfs` / `initramfs`), постоянные дисковые разделы `FAT32` (с поддержкой длинных имен LFN), псевдофайловые системы `/proc` и `/sys`, и аппаратные узлы `/dev`.
* **Wunix Network Stack**: собственный высокопроизводительный сетевой стек на Rust (L2/L3/L4: Ethernet, ARP, IPv4, ICMP, UDP, TCP) поверх драйвера VirtIO-Net.
* **Wunix Security**: модель разграничения прав доступа, база пользователей и групп (`/etc/passwd`, `/etc/shadow`, `/etc/group`, `/etc/sudoers`), утилиты `login`, `su`, `sudo`, `sudoadd`, маскировка паролей и изоляция адресных пространств процессов (Ring 3).
* **Wunix Installer & Boot**: загрузочное меню Limine (Live-ISO / Install), автономная загрузка с диска или флешки и TUI-установщик `winstall` с визуальной разметкой MBR/GPT.
