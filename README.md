# Документация Wunix

Добро пожаловать в официальную документацию операционной системы **Wunix** — независимой UNIX-подобной операционной системы, разрабатываемой на языке Rust.

---

## Карта документации

Документация структурирована по специализированным разделам:

### 1. Архитектура и дизайн системы ([`architecture/`](architecture/))
- **[Общая архитектура Wunix](architecture/overview.md)** — концепция системы, принципы безопасности памяти, архитектурные слои (Applications, Desktop, Base, Core), пакетная система (WPM/WSP) и модель релизов.
- **[Архитектура ядра Wunix Core](architecture/kernel.md)** — внутреннее устройство ядра: 64-битный режим, протокол загрузки Limine, Higher-Half память, физический и виртуальный аллокаторы, прерывания и драйверная подсистема.

### 2. Интернационализация и локализация ([`i18n/`](i18n/))
- **[Обзор подсистемы i18n](i18n/README.md)** — архитектурные принципы локализации ядра, lock-free хранилище языка (`AtomicU8`), параметры загрузки `cmdline`, шрифты и переключение раскладок.
- **[Руководство: Как перевести Wunix на свой язык (Русская версия)](i18n/translation-guide.ru.md)** — пошаговая инструкция для переводчиков (гуманитариев) и разработчиков (технарей).
- **[Guide: How to Translate Wunix into Your Language (English version)](i18n/translation-guide.en.md)** — complete translation guide for writers, translators, and systems engineers.

### 3. Дорожная карта разработки ([`roadmap/`](roadmap/))
- **[Дорожная карта и статус фаз разработки](roadmap/roadmap.md)** — 7 фаз развития Wunix от первичного bring-up железа до пользовательского пространства (Ring 3) и оболочки WSH.

### 4. Руководства разработчика ([`guides/`](guides/))
- **[Сборка, запуск и отладка](guides/development.md)** — требования к окружению, компиляция ядра, параметры виртуализации QEMU, аппаратное ускорение KVM и логирование через COM1.

## Быстрый старт

Сборка ядра и запуск в эмуляторе QEMU выполняются одной командой:

```bash
# Запуск с русским языком сообщений (по умолчанию):
./tools/run.sh

# Запуск с английским языком сообщений:
./tools/run.sh en
```

Подробнее о параметрах памяти, процессора и скрипта запуска см. в [Руководстве по разработке](guides/development.md).
