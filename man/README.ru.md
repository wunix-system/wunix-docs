# Руководство по man-страницам Wunix (Manual Pages)

В операционной системе Wunix реализована классическая система встроенной документации UNIX — страницы руководства (**man pages**). Все системные утилиты пространства пользователя снабжены документацией в формате roff/groff на двух языках (русском и английском).

---

## 1. Использование утилиты `man`

В интерактивной командной оболочке `wsh` встроенная утилита `man` позволяет быстро получить подробную справку о синтаксисе, параметрах и примерах использования любой команды:

```bash
# Просмотр справки по утилите:
man ls
man ping
man mount

# Явное указание раздела руководства:
man 1 cat
man 8 fdisk
```

Язык отображения справки автоматически адаптируется под системную локаль пользователя:
- При русской локали (`ru`) читаются страницы из каталога `/usr/share/man/ru/`.
- При английской локали (`en`) читаются страницы из каталога `/usr/share/man/en/`.

---

## 2. Разделы руководства (Sections)

Документация Wunix разделена по стандартным секциям UNIX:

- **Раздел 1 (`man1`)**: Пользовательские команды и интерактивные утилиты.
- **Раздел 8 (`man8`)**: Команды системного администрирования и управления устройствами.
